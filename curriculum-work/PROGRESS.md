## 작업 전 추론 강도 안내 — 사용자 요청

강의 제작 완료까지 각 다음 작업을 시작하기 전에 **진행할 작업 / 추천 추론 강도 / 이유**를 짧게 알린다. 같은 강도를 유지하는 경우에도 다음 작업의 추천을 명시한다. 작업 중 복잡도가 달라져 상향을 추천할 때도 변경 이유를 알린다.

이 안내는 설정 변경을 수행했다는 뜻이 아니다. 실제 추론 설정은 사용자가 선택한다. 강도 안내만을 이유로 매 작업마다 승인 질문을 반복하지 않는다. 일반적인 작업 묶음은 이미 정한 강도와 범위 안에서 계속 진행하며, 상위 강도 적용이 꼭 필요한 작업은 필요한 이유와 다음 행동을 명확히 알린다.

**바로 다음 작업:** K2-10/L5 Single-Agent. **추천: High.** 모델의 Tool 선택과 Runtime의 검증·허용·실행·종료를 분리해야 한다.

## 다음에 바로 할 일

KEDU-PRODUCTION-007을 진행한다. 실제 검색을 허용 목록의 Tool로 제공하고 Schema·Registry·입출력 검사·State·종료 상한을 만든다. 모델이 전달한 승인/권한 값을 신뢰하지 않는다. 먼저 고정 응답으로 경계를 검사하고 준비된 로컬 모델의 실제 선택·실패도 구분해 기록한다. 유료 API를 전제로 삼지 않는다.

L4의 품질은 미통과다. v1은 주로 자료 부족으로 답했고 v2는 일부 인용이 생겼지만 틀린 금액·무관한 근거·조건 누락·공격 값 반복이 남았다. 사실 6개 완전 통과는 두 버전 모두 0개, 경계 행동 완전 통과는 v1 3/6·v2 1/6이다. 같은 Work 원문 대조이며 독립 채점이 아니다. Agent를 붙인 사실로 이 문제를 해결됐다고 표시하지 않는다.

이번에는 E5-small과 Qwen3-0.6B를 CPU에서 실제 실행했다. 본 실험 29회·C01 캐시 재실행 2회, 실제 생성 31회·유료 API 0회다. C01은 실제 한 번의 형식 보완 후 초안 반환, C03/C04는 반복 실패 뒤 초안 없이 종료했다. C01 재실행은 원응답·초안이 같고 요청 가드 HTTP 시도 0회다. 기존 164개와 L4 20개를 합쳐 184개 테스트가 통과했다.

## 남은 검증·제작

L4는 CLI의 실제 로컬 생성 경로를 확인한 것이다. 기존 L0 웹 API의 실제 Ollama/OpenAI 생성이나 L1의 다섯 조건 전체 생성 비교를 끝낸 것은 아니다. L4 실제 흐름과 과거 보고서의 미확인을 섞지 않는다. CPU 환경은 L3 패키지를 재사용했으며 다른 운영체제·GTX 1060 3GB·교육장 동시 실행은 미검증이다.

L5 Single-Agent → L6 Multi-Agent, 별도 L7 실제 훈련·저장·새 프로세스 Reload, L8/L9 문서 확장·통합을 이어간다. 나머지 기초/안내 단원도 전체 완료 전에 작성해야 한다. 인증·승인 저장소·외부 부작용 Tool·진행 중 강제 취소·UI·독립 수업 평가는 남아 있다. 작성 수를 품질·수업 검증 완료 수로 표시하지 않는다.
