## 작업 전 추론 강도 안내 — 사용자 요청

강의 제작 완료까지 각 다음 작업을 시작하기 전에 **진행할 작업 / 추천 추론 강도 / 이유**를 짧게 알린다. 같은 강도를 유지하는 경우에도 다음 작업의 추천을 명시한다. 작업 중 복잡도가 달라져 상향을 추천할 때도 변경 이유를 알린다.

이 안내는 설정 변경을 수행했다는 뜻이 아니다. 실제 추론 설정은 사용자가 선택한다. 강도 안내만을 이유로 매 작업마다 승인 질문을 반복하지 않는다. 일반적인 작업 묶음은 이미 정한 강도와 범위 안에서 계속 진행하며, 상위 강도 적용이 꼭 필요한 작업은 필요한 이유와 다음 행동을 명확히 알린다.

**바로 다음 작업:** Embedding 네 단원과 연결 실습(L3)의 표현·유사도·Hybrid 부분을 수정·재검수한다. **추천: High.** 문장/Token/내부 표현/검색 벡터의 연결과 수치 계산·실제 검색 관찰을 풀어 설명해야 한다. 기존 유용한 계산·모델/데이터·인덱스 운영 부분은 보존하고 영향 받은 범위만 검증한다.

QLoRA·독립 의미/수업 검증과 기존 품질 게이트는 별도 미완료로 유지한다. 전체 예제를 봤다는 사실을 수렴·운영 품질로 표시하지 않는다.

## Context 수정 결과

자료의 허용/현행/근거 적합성, 질문별 문서 선택, 같은 본문의 순서 변경, 출력 여유 포함 예산, 과거 상태와 현재 문서/버전 전달을 설명·예제·활동으로 연결했다. Prompt 본문/해설과 공통 실습의 Context 안내 밖 내용은 보존했다. 새 관찰 도구는 기존 준비 함수만 재사용한다. 지시/본문/질문 보존, 현재 가용 문서, 과거 Token 관찰 입력 해시와 산술, 입력 변경 시 과거 값 재사용 거부를 확인했다. Tokenizer/캐시·모델·고정 HTTP 환경·수업을 새로 검증한 것은 아니다. 보조 실행 환경은 Python 3.12.14/Pydantic 2.14.1이며 고정 요구 2.14.2와의 차이를 기록했다. [이번 결과](reports/KEDU-TEACHING-REPAIR-004/RESULT.md)로 이어간다.
