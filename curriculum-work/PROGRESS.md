## 작업 전 추론 강도 안내 — 사용자 요청

강의 제작 완료까지 각 다음 작업을 시작하기 전에 **진행할 작업 / 추천 추론 강도 / 이유**를 짧게 알린다. 같은 강도를 유지하는 경우에도 다음 작업의 추천을 명시한다. 작업 중 복잡도가 달라져 상향을 추천할 때도 변경 이유를 알린다.

이 안내는 설정 변경을 수행했다는 뜻이 아니다. 실제 추론 설정은 사용자가 선택한다. 강도 안내만을 이유로 매 작업마다 승인 질문을 반복하지 않는다. 일반적인 작업 묶음은 이미 정한 강도와 범위 안에서 계속 진행하며, 상위 강도 적용이 꼭 필요한 작업은 필요한 이유와 다음 행동을 명확히 알린다.

**바로 다음 작업:** K2-07/K2-08/L3 검색용 표현·Index 강의/실습. **추천: High.** ID·Token·Embedding의 차이와 실제 검색·필터·갱신·삭제 계약을 같은 앱에 연결해야 한다.

## 다음에 바로 할 일

KEDU-PRODUCTION-005를 진행한다. 같은 가상 문서·12개 공통 사례·L2 실행 기록을 이어받아 검색용 표현과 Index를 만든다. 수동 문서 선택을 실제 검색으로 바꾸면서 출처 ID/버전·제한 문서 제외·갱신/삭제 후 행동을 검사한다. 사용할 모델·의존성·장비는 실제 준비 상태로 확인한다.

L0/L1/L2의 G-MODEL 실제 생성과 사람 채점은 독립 미완료다. 이번 고정 응답 10개 실험이나 A/B 구조 비교를 모델 성능으로 기록하지 않는다. 승인 저장소·인증·부작용 Tool·강제 취소·Token/비용 강제 상한·React UI도 구현 완료로 표시하지 않는다.

이번 환경에서 기존 93개와 새 L2 43개를 합쳐 136개 테스트를 통과했다. Provider 시도 총 3회, 통신 재시도 1회, 출력 보완 1회를 공유하고 실패/늦은 결과를 초안으로 승격하지 않는 동작을 확인했다. 90초는 호출 전후 경과시간 검사이며 진행 중 요청을 끊지 않는다. 과거 보고서는 변경하지 않았다.
