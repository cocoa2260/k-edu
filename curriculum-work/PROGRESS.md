## 작업 전 추론 강도 안내 — 사용자 요청

강의 제작 완료까지 각 다음 작업을 시작하기 전에 **진행할 작업 / 추천 추론 강도 / 이유**를 짧게 알린다. 같은 강도를 유지하는 경우에도 다음 작업의 추천을 명시한다. 작업 중 복잡도가 달라져 상향을 추천할 때도 변경 이유를 알린다.

이 안내는 설정 변경을 수행했다는 뜻이 아니다. 실제 추론 설정은 사용자가 선택한다. 강도 안내만을 이유로 매 작업마다 승인 질문을 반복하지 않는다. 일반적인 작업 묶음은 이미 정한 강도와 범위 안에서 계속 진행하며, 상위 강도 적용이 꼭 필요한 작업은 필요한 이유와 다음 행동을 명확히 알린다.

**바로 다음 작업:** K2-11/L6 Multi-Agent·Handoff. **추천: High.** 역할별 State·허용 자료·요청/검토와 전체 예산을 연결해야 한다.

## 남은 검증·제작

LangChain Core 1.7.3 StructuredTool의 도구 연결 계약만 검사했다. Framework Agent 전체·MCP 통신·실제 사용자 인증·지속 승인·외부 부작용은 미구현이다. 모의 승인 저장은 메모리뿐이며 실제 메시지를 보내거나 파일을 쓰지 않는다. 180초는 호출 전후 검사이고 진행 중 강제 중단이 아니다.

L4 품질 미통과, L0 웹 API의 실제 Ollama/OpenAI 생성, L1 다섯 조건 전체 생성 비교, 독립 수업·UI·교육생 장비/동시 실행 검증도 독립 미완료다. L6 → 별도 L7 실제 훈련·저장·새 프로세스 Reload → L8/L9 문서 확장·통합을 이어가며 나머지 기초/안내 단원도 전체 완료 전에 작성한다. 작성 수를 품질·수업 완료 수로 표시하지 않는다.
