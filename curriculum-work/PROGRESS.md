## 다음에 바로 할 일

첫 미완료 항목은 **HF-TOKENIZER-ACTUAL**이다. [실습 안내](practice/huggingface-tokenizer/README.md)에 따라 PyPI·Hugging Face 파일 접근이 가능한 Python 3.12 격리 환경에서 직접 의존성을 설치하고, 고정된 Tokenizer 파일만 확보한다. Qwen 실제 관찰 → 같은 캐시 재실행 → 길이 16 변경 → Smol 비교 순서로 실행한다. 실제 결과와 설정/파일 해시를 검토한 뒤 제작 결과와 단원 상태를 갱신한다.

현재 requirements는 직접 버전을 정한 후보이며 설치·전체 전이 의존성·교육장 검증을 마친 Lock이 아니다. 공개 원본 페이지와 리비전 메타데이터를 읽은 사실도 Tokenizer 실제 실행 성공과 구분한다.

## 중단 후 재개 방법

1. 이 파일을 읽고 [단원별 기록](curriculum/production-index.json)의 첫 미완료 Gate를 확인한다.
2. 위 작업 브랜치의 최신 커밋과 작업 파일을 확인한다. 기존 강의 전체를 다시 분석하지 않는다.
3. 미완료 Gate만 이어서 실행한다. 코드/의존성/모델 파일을 바꿨다면 영향을 받는 검사만 다시 수행한다.
4. 실제 실행을 통과한 항목과 남은 항목을 기록하고 커밋한다. 예상 결과를 관찰 결과로 채우지 않는다.

재개 지시 예: “cocoa2260/k-edu의 work/curriculum-production-001에서 curriculum-work/PROGRESS.md를 읽고 첫 미완료 검증부터 이어서 진행해.”
