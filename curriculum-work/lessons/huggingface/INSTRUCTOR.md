# 강사용 진행·평가 안내

첫 제작 묶음 KEDU-PRODUCTION-001. 이 강의는 PRE-HF와 K2-03.U05~07의 공통 원본이다. PRE-HF에서는 첫 모델 사용 전에 화면 탐색·Card 활동을 하고, K2-03에서는 Tokenizer·Template 관찰까지 심화한다. 같은 화면 설명을 두 강의에 복사해 따로 수정하지 않는다.

## 진행 원칙

학생에게 먼저 ‘모델을 골라서 답변을 생성하라’고 요구하지 않는다. 검색 목적과 페이지를 읽는 순서를 알려주고 파일·리비전·실행 경로를 찾게 한다. Python을 아직 배우지 않은 학생은 화면 활동을 완료하고, Python 선수학습 뒤 실행 활동으로 돌아온다.

교사는 시연 전에 선택 리비전 접근·필요 파일·Python 설치/의존성·실제 관찰·캐시 재실행을 확인한다. 의존성이 없는 상태의 preflight나 계약 테스트를 실제 Tokenizer 실행 결과로 제시하지 않는다. 강의 제작 기록에 미검증이면 교실 시연 전 검증이 필요하다.

화면은 2026-10-30의 실제 캡처다. 최신 UI와 다르면 학생에게 위치 암기를 요구하지 말고 Model card·Files·실행 도구라는 정보의 의미를 기준으로 안내한다. 이후 검색 Filter·Files/History·Dataset Viewer 화면을 추가할 때도 날짜/URL·보는 이유·확인 질문을 함께 작성한다.

## 완료 판단

| 영역 | 확인할 근거 | 부족한 경우 |
|---|---|---|
| 메뉴 선택 | 목적에 맞는 Models/Datasets/Spaces/Docs 선택 이유 | 단어의 뜻과 실제 자료를 연결해 재탐색 |
| 모델 판단 | 두 Card/파일에서 Task·언어·License·실행 경로 근거와 미확인 조건 | 모델 인기/크기만으로 고르면 근거 보완 |
| 입력 이해 | 실제 IDs/decode·길이·Padding·Template 관찰값과 해석 | 예상 숫자를 적으면 실제 실행 상태부터 재확인 |
| 재현 | 동일 Revision·입력·옵션의 캐시 재실행 비교 | 시각만 다른 것과 관찰값 차이를 구분 |

점수를 임의로 고정하지 않았다. 과제의 필수 증거를 충족하는지 판정한다. 환경 준비 때문에 실행하지 못한 경우 개념 활동과 실행 상태를 별도로 기록한다. 개념을 설명한 사실을 실행 완료로 대체하지 않는다.

## 예상 답의 핵심과 오답 처리

- Model Card에 정보가 없으면 ‘미확인 + 확인 방법’도 올바른 답이다. 모델 이름 하나를 정답으로 고정하지 않는다.
- Token 수는 Tokenizer와 입력에 따라 달라진다. 한국어/영어 예문 길이 차이와 의미 차이도 있어 몇 문장만으로 언어 전반의 효율/품질 순위를 만들지 않는다.
- 내부 Token 표시와 전체 decode를 함께 본다. Token 표시가 자연어처럼 보이지 않는다는 이유만으로 실행 실패로 채점하지 않는다.
- 입력 ID의 의미는 해당 Tokenizer의 어휘 규칙 안에서 해석한다. 다른 모델의 동일 숫자 ID에 같은 의미를 부여하지 않는다.
- 잘림은 모델에 들어가는 정보 자체를 바꾼다. 규정의 예외 조건이 잘리는 예를 학생의 문장으로 만들어보게 한다.
- Padding mask의 0은 패딩 위치다. SFT 정답 부분을 선택하는 Loss mask는 후속 K2-12.U04에서 별도 확인한다.
- Template 결과는 모델 입력이다. Qwen의 enable_thinking 옵션에 따른 문자열을 실제 생성/추론의 증거로 해석하지 않는다.
- 특수 Token 재추가의 영향은 Tokenizer 설정에 따라 다르다. 변화가 없다는 관찰도 틀린 답이 아니며 이유를 확인하게 한다.
- 설치한 도구가 없거나 캐시가 없을 때 종료 코드 2가 나온 사실은 준비 필요를 정확히 알린 것이다. 실제 관찰의 통과 여부와 분리한다.

## 후속 연결

다음 묶음은 L0 기준 환경/Provider 계약을 고정하고 K2-04~06 / L1~L2로 연결한다. 이번에 확인한 모델 ID·리비전·Tokenizer·Template·입력 길이를 기준 정보로 재사용한다. 실제 생성 모델의 한국어 품질·메모리·지연과 Tool 출력 적합성은 G-MODEL에서 새로 검증해야 한다.

PEFT 계열별 비교와 Dataset 제작은 이번 강의에서 이름과 역할만 안내한다. 실제 LoRA/QLoRA·선택 IA3/DoRA 비교는 K2-12에서 같은 데이터/평가·학습량·메모리/시간을 기록하는 별도 실습으로 수행한다.
