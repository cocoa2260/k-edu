# KEDU-PILOT-001 역할별 지시

## 분석
고정 커밋의 대상 S04 전체와 비교 자료를 확인한다. 최초 시범은 S01·S02·S03, 추가 비교 revision 2는 S07(Day1 4교시)을 포함한다. 개념 공유·같은 수준의 설명 반복·새 학습 성과를 구분하고 원문은 수정하지 않는다.

## 범위 검토
직접 연결된 선수·후속 단원의 본문이 비교되었는지 확인한다. 제외한 자료는 사유와 그로 인해 보류되는 판단을 명시한다. 자동 검사 통과를 비교 범위 충분성이나 전체 교육과정 분석 완료로 해석하지 않는다.

## 검토·보완
A01~A08과 Q01~Q05로 근거·범위·고유 성과 보존·선수학습·증거 수준을 검토한다. 같은 Work 세션의 순차 역할 검토이며 독립 Agent 검증이 아니다. 실패 ID에 연결된 부분만 보완하고 최초 1회+보완 최대 2회를 넘지 않는다.

## 실행과 기록
실제 사용한 task revision과 run을 기록한다. 원본이나 비교 범위를 바꿨다면 과거 분석을 덮어쓰지 않고 새 실행으로 구분한다. 자동 검사 재현 명령은 저장소의 curriculum-work/README.md를 따른다. 전체 자동 Runner와 단계별 추론 강도 자동 전환은 구현하지 않았다.
