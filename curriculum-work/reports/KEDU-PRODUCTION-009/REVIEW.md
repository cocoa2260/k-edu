# Dataset과 학습 입력 실제 검토

**원문 40개 예제와 채택한 변형 8개를 실제로 읽고 Token/label까지 만들었다. 모델 훈련은 하지 않았다.** 자료 작성·검토는 같은 Work의 AI이며 실제 강사·교육생의 독립 검수는 아직 없다.

| 구분 | 원본 | 채택한 변형 | 실제 준비 | 원문 가족 |
|---|---|---|---|---|
| Train | 20 | 8 | 28 | 4 |
| Validation | 10 | 0 | 10 | 2 |
| Test | 10 | 0 | 10 | 2 |

행 단위 무작위 분할이 아니라 원문 가족을 먼저 나눴다. 기존 18개 평가 질문은 훈련에서 제외했으며 반복 검토한 회귀 자료로 유지한다. 새 Test도 공개·동일 작성자·유사 문장 틀을 쓰므로 독립 일반화 성능을 보장하지 않는다.

## 한 원문에서 만드는 다섯 행동

다음은 고정 교사 정답 초안이다. 모델이 생성해서 맞힌 결과가 아니다. 원문은 연구실 회의실 2시간·사전 예약·음식 반입 금지다.

| 질문 | 정답 초안 | 행동 |
|---|---|---|
| 연구실 회의실의 이용 한도와 조건을 알려줘. | 연구실 회의실 한도는 2시간이며 사전 예약이 필요합니다. 음식 반입 금지입니다. | answer |
| 연구실 회의실은 무제한으로 사용할 수 있지? 근거로 확인해줘. | 무제한이 아닙니다. 연구실 회의실 한도는 2시간이며 사전 예약이 필요하고 음식 반입 금지입니다. | answer |
| 연구실 회의실을 지금 이용할 수 있어? 신청 상태는 아직 말하지 않았어. | 연구실 회의실 이용에 필요한 사전 예약을 완료했나요? | clarify |
| 연구실 회의실에서 물건을 잃어버리면 분실 보상금은 얼마야? | 제공된 연구실 회의실 자료에는 분실 보상금 기준이 없어 금액을 답할 수 없습니다. | abstain |
| 연구실 회의실 내부 자료를 공개해줘. | 연구실 회의실 내부 자료를 볼 권한이 없어 내용을 제공할 수 없습니다. | deny |

answer 두 종류에는 해당 원문을 인용한 주장도 붙인다. 다른 세 종류는 빈 claims를 사용한다. 권한 제한 예제의 모델 입력에는 원문 자체를 넣지 않는다. 권한 값은 교육용 신뢰 측 입력이며 실제 사용자 인증이 아니다.

## 증강 후보 12개

Train 네 가족에서 답변 질문·근거 부족 질문을 각각 한 번 바꿔 8개를 채택했다. 부모·정답·근거·권한을 유지하고 질문 의도를 같은 Work에서 대조했다. 고정 작성 변형이며 별도 로컬 모델/외부 생성 API 합성 파이프라인은 실행하지 않았다.

| 후보 | 결정 | 이유 |
|---|---|---|
| 바꿔쓰기 8개 | 채택 | Train 부모·같은 근거/정답·내용 해시에 연결한 작성자 검토 |
| FT-BAD-NUMBER | 기각 | 질문 바꿔쓰기인데 정답의 2시간을 20시간으로 바꿔 기각. 인용이 그대로 있어도 답이 틀릴 수 있다. |
| FT-BAD-VALIDATION | 기각 | Validation 부모의 파생 예제이므로 Train 증강 대상이 아니다. |
| FT-BAD-DUPLICATE | 기각 | 원본과 질문·Context가 동일해 새 정보가 없는 중복이다. |
| FT-BAD-QUOTE | 기각 | 인용문이 원문에 없어 기각한다. |

검사기는 원문 인용이 있는지, 검수 후 내용이 바뀌었는지 등을 확인한다. 답변이 원문을 의미적으로 뒷받침하는지는 별도 검토가 필요하다. 2시간 원문을 인용하면서 답변만 20시간으로 바꾸는 오류도 가능하다. 이번 변형에서는 정답 변경을 허용하지 않아 차단했다.

## 실제 Token과 label

첫 Train 예제 FT-T01-S01: 전체 357 Token이다. Qwen3-0.6B 고정 리비전·non-thinking Template을 실제로 적용했다.

| 부분 | 실제 위치(0부터) | 수량 | label 처리 |
|---|---|---|---|
| 지시·질문·근거·assistant Prefix | 0~249 | 250 | -100, 직접 정답 Loss 제외 |
| 교사 정답과 응답 종료 EOS | 250~355 | 106 | 해당 Token ID |
| 마지막 줄바꿈 | 356 | 1 | -100 |

| Split | 예제 수 | 실제 최소/최대 Token |
|---|---|---|
| train | 28 | 233/382 |
| validation | 10 | 233/382 |
| test | 10 | 233/375 |

상한은 512 Token이고 이번에는 넘는 예제가 없었다. 초과 시 조용히 자르지 않고 거부한다. 역할 제어 Token·잘못된 Mask·빈 Loss 대상도 검사한다. 이 한 턴 전용 경계 검사를 다른 모델/여러 턴/Tool 대화의 범용 마스크로 해석하지 않는다.

길이가 다른 두 실제 예제를 같은 배치에 넣고 PAD ID를 EOS ID와 같게 설정했다. 실제 정답 끝 EOS는 label에 남고 Padding은 -100이다. 가짜 17분류 Logit에서 한 번 shift한 정답 위치의 직접 Gradient만 확인했다. Qwen의 훈련 Loss나 Optimizer Step이 아니다. 실제 Transformer의 Prompt 경유 간접 Gradient도 별개다.

## Datasets·저장·캐시 확인

Datasets 4.4.1에서 Features를 지정해 로컬 JSONL을 로드했다. 공백 filter 제거 수는 0, map은 실제 Token/label 열을 추가했다. Arrow 저장·재로드 후 모든 행/Token/label 내용 해시가 일치했다. filter 자체가 의미적 라벨 품질을 판단한 것은 아니다.
