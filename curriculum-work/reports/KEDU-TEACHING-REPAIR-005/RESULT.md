# Harness 교안·연결 실습 수정 결과

**Harness 다섯 단원과 연결 실습을 수정하고 동일 작성자의 설명 검수를 마쳤다.** 실제 식비 질문에서 호출·검사·재시도/보완·종료를 끝까지 읽고 결과의 의미와 한계를 설명하도록 바꾸었다.

학생은 **[수정한 강의](../../lessons/harness/lesson.md)** → **[연결 실습](../../practice/document-assistant/L2.md)** 순서로 사용한다. **[강사용 해설](../../lessons/harness/teacher-guide.md)**에는 장별 질문·활동 판정·기존 단원 매핑이 있다. 관리 보고서/JSON 전체를 핵심 설명 대신 읽게 하지 않는다.

| 수정한 내용 | 실제 예제와 관찰 |
|---|---|
| 한 요청의 전체 흐름 | 사람이 작성한 식비 답안의 JSON→입력 준비→고정 응답 호출→검사→사람 검토용 초안 |
| 통신 재시도와 보완 | 같은 입력의 시간 초과 재시도, 실패 안내만 추가한 보완 입력, 같은 검사 재실행과 공유 예산 |
| 구조와 내용 | 제공한 DOC-A로 틀린 999999원을 써도 구조 통과. 원문 30,000원과 사람의 의미 대조는 별도 |
| 개선과 회귀 | 구조 통과 9→10이어도 첨부 메모 사례 회귀. 고정 출력 A/B를 모델/Prompt 성적으로 보고하지 않음 |
| 승인·시간·취소 | 추가 승인 필드 거부, 가짜 시계 91초/취소 신호 뒤 정상 응답 폐기, 실제 강제 중단과 구분 |

단일 식비 시연과 기존 기록을 읽기 쉽게 표시하는 `tools.harness_steps`를 추가했다. 기존 Harness·데모·테스트·입력/자료·API는 보존했다. 실제 모델이나 복제 앱을 추가하지 않았다.

## 실행 확인

- 기존 데모 명령을 실행해 열 가지 고정 응답 실험과 같은 12사례 A/B를 새로 관찰했다. 기존 출력 파일 덮어쓰기 거부도 확인했다.
- 열 실험의 시도/재시도/보완·종료 이유가 교안과 일치했다. 기록 표시·회귀 비교·가짜 시계/취소 시연과 잘못된 파일/옵션 거부를 확인했다.
- 통신 재시도의 입력 동일성, 보완 실패 안내와 실패 응답 전문·평가 정답 비복사, 보완 뒤 통신 재시도의 직전 입력 동일성, 총 상한·부분 예산·프로그래밍 오류 전파를 직접 확인했다.
- 늦은 응답과 호출 중 취소는 초안 없이 종료했고 호출 전 취소는 호출 0회였다. 가짜 91초는 실제 대기/강제 중단 시험이 아니다.
- 교안의 실행 가능한 Python 코드블록 세 개을 실행했고 JSON 예가 실제 단일 시연 결과와 같았다. 검사 코드 발췌 두 개는 원래 소스와 대조했다. 기존 코드/자료와 앞의 Prompt·Context 본문은 변경하지 않았다.

**보조 환경은 Python 3.12.14/Pydantic 2.14.1**이며 학생용 고정 요구 Pydantic 2.14.2와 다르다. Pytest/FastAPI가 설치된 전체 고정 환경을 재검증한 결과는 아니다. 과거 136개 테스트 통과 기록을 이번의 새 검사 수로 보고하지 않는다. 이번에는 관련 제어/입력 경계를 직접 실행했다.

검사 중 네트워크 연결/주소 조회 시도를 감시했고 0회였다. 실제 모델·유료 API 호출도 0회다. 시연의 Provider 시도는 모델 추론 수가 아니며 Token·비용은 미확인이다. 실제 모델 정상/보완/종료·의미 평가, 실제 장애/인증/강제 중단·독립 수업·교육장 검증은 남아 있다.

## 판정과 다음 작업

이번 판정은 **설명·실습 연결의 동일 작성자 검수 통과**다. 기준별 실제 근거와 실행 범위는 [검증 기록](validation.json)에 있다. 코드 검사 수나 파일 길이로 설명 품질을 자동 판정하지 않았다.

Prompt·Context·Harness 13개 단원 정비를 기록했고 나머지 57개는 검사 결과에 따라 정비해야 한다. 전체 모델 품질·QLoRA·통합/수업의 기존 미완료는 그대로 남긴다.

다음은 **Embedding 네 단원과 직접 연결된 실습 수정·재검수**, 추천 추론 강도는 **High**다. 표현/유사도/Hybrid 개념과 기존 유용한 수치 예제·실제 검색 관찰의 연결을 확인해야 한다. 인덱스 운영 부분은 이후 정비 대상으로 보존한다.
