# Index 운영 교안·연결 실습 수정 결과

**Index 네 단원과 연결 실습을 수정하고 같은 작성자가 설명·예제·실제 동작을 재검수했다.** 독립 강사/교육생 수업 검증은 아니다. 이번까지 이 기준의 설명 검수 범위는21개이며 나머지49개 단원 정비와 실제 품질/수업 게이트는 남아 있다. 파일 작성 수70/70과 구분한다.

[학생 강의](../../lessons/vector-index/lesson.md) · [연결 실습](../../practice/document-assistant/L3.md#index-활동) · [강사 해설](../../lessons/vector-index/teacher-guide.md)

## 설명과 실습에서 바꾼 것

- 한 식비 결과에서 본문/벡터/Metadata 역할, 실제 저장 테이블과 응답, 문서/버전/내부 줄·전체 본문 해시·최초 경로/논리 위치를 연결했다. 실제 JSON 발췌와 원문 대조 코드를 제시했다.
- 다섯 점의 Exact 순위와 한 구역만 탐색한 누락을 먼저 계산했다. 직접 구성한 그래프의 막힘/후보 유지/윗층 연결, 구역 중심과 개별 점의 거리 차이로 HNSW·IVF의 핵심을 설명했다. 실제 알고리즘/FAISS 내부 경로와 구분했다.
- 기존 FAISS 합성 실험을 보존해 같은 벡터/질의/거리/k와 측정 범위를 설명했다. 첫 질의 이웃 회수와128질의 평균을 분리하고 첫 질의의 교집합만 독립 재계산했다.
- 실제 임시 SQLite에 비의미 고정 벡터를 넣어 필터→원문 재조회→갱신/이전선택거부→삭제→원본 재구축을 관찰하게 했다. 원본으로 재구축하면 삭제 자료가 복귀하는 이유까지 설명했다.
- 개념별 질문12개·해설, 다섯 Index 활동과 선택 FAISS 활동에 시작 상태/명령/관찰/해석·오류 안내를 붙였다. 새 도구의 기본 출력은 요약이고 전체 JSON 저장은 선택이다. 기존 Embedding 본문/해설과 L3의 Embedding·모델 실행 안내는 보존했다.

## 실제 확인한 범위

Python3.12.14 표준 라이브러리에서 작은 계산과 기존 SQLite 구현을 실행했다. 새로운 E5/Tokenizer/FAISS/유료 API 실행은 없다.

| 근거 | 이번에 확인한 것 | 해석 범위 |
|---|---|---|
| 직접 정한 L2좌표/연결/중심 | Exact C→D→B→A→E, A→B 막힘과 다른 경로, U만 D·B/회수0.5, 둘 다 C·D/회수1 | 원리 설명용 계산. E5·실제 HNSW 구축/탐색이 아님 |
| 현재 기존 LocalIndex+고정 벡터 | 초기6/11→갱신7/10→삭제8/9, 기본 적격9, v1/30000→v2/35000, stale거부·본문 재조회·벡터0·삭제 표식·설정 거부·재구축v1복귀 | 실제 임시 SQLite 제어 동작. 검색 의미 품질/인증/동시 분산/안전 삭제가 아님 |
| 직접 경계 검사 | 제한/가용 목록 배제, 제한 조각 위조 거부, 잘못된 새 벡터가 기존 본문/변경번호를 보존, 다른 문서 변경도 이전 선택 거부 | 현재 수업 설명에 직접 필요한 코드 동작. 전체 기존 Pytest 재실행은 아님 |
| 과거 실제 E5/SQLite 기록 읽기 | 갱신/삭제 전 선택 거부, 새 Context, 삭제 뒤 ID, 설정/재구축과 기존512/128 표시값 오류 확인 | 저장된 실제 모델 관찰 재사용. 새 모델 실행 아님 |
| 과거 합성 FAISS 기록 읽기 |6조건, 첫 질의 교집합/누락 ID 재계산, 전체 평균/배치 ms와 구분 | 전체128질의 ID가 없으므로 전체 평균 독립 재계산은 하지 않음 |
| 본문/도구 대조 | 새 전체 코드2개 실행, JSON/소스 발췌 일치, CLI4모드와 잘못된 입력/파일/중복 ID·덮어쓰기 거부 | 새 명령/설명의 일치와 한정된 실행 |

직접 검사와 CLI 자식 프로세스에 연결 시도 거부 가드를 두었고 연결 시도를 관찰하지 않았다. 이것은 OS 네트워크 격리 검증이 아니다. 새 관찰 JSON은 가상/현재SQLite/저장기록 읽기를 각각 evidence_kind로 표시한다. 모델·SQLite 바이너리나 원본 자료를 Git에 추가하지 않는다. 과거 보고서 수치를 이번 새 실행의 지표로 고쳐 쓰지 않는다.

## 보존과 남은 일

기존 LocalIndex와 지난번 Manifest 독립 복사, E5 인코더/모델 설정, 검색/ANN 실행 도구, 원본 자료/질문/정답·API·기존 테스트/보고서는 그대로다. 새 도구는 이 구현을 호출해 관찰할 뿐 검색 API나 인증 기능을 추가하지 않는다. 실제 E5·캐시/FAISS 재실행·전체 Pytest/HTTP 환경·Reranker/다른 가중치 모델 전환·교육장 장비/UI/독립 수업은 이번에 실행하지 않았다.

가상 그래프는 직접 정한 연결이며, 단순 후보 확장을 HNSW의 실제 종료/탐색 규칙으로 가르치지 않는다. 고정 벡터 실습의512/128은 설정 호환성 시연이며 실제 Token 길이 검사가 아니다. 과거 E5의512/128 기록 오류는 보존된 원본과 [이전 수정 기록](../KEDU-TEACHING-REPAIR-006/RESULT.md)에 연결한다. 삭제 후 재구축은 원본 복구 시험이므로 운영 삭제 유지 성공으로 표시하지 않는다.

상세 기준별 근거와 실행 범위는 [validation.json](validation.json)에 남긴다. 현재 전 과정 완료·실제 답변 품질 채택·독립 수업 통과는 아니며 기존 미완료 게이트를 유지한다.
