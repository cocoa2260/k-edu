## 수정 이유와 설명 흐름

기존 상세 설명·실행 한계는 유지하면서 관리 ID 도입을 상황 설명으로 바꾸고 예제/활동 연결을 보강했다. 입력 5+출력 여유 16의 21예약·두 번 42예약과 Context/공유 예산 차이, 실패 예약 무환급과 대체 경로 판정을 풀었다. 원문 접근과 외부 전송, 기능과 현재 준비 상태·건강 관찰의 차이를 설명했다.

한글 UTF-8 3바이트와 SSE 프레임·모델 Token을 구분하고 설명용 start/delta/final 입력과 실제 consume 함수의 메모리 응답 실습을 연결했다. 부분 문장과 확정 answer, final 없는 EOF, 이전 실행의 늦은 취소 접수, 생성 완료와 전송/의미 승인의 차이를 설명했다. 세 형식의 표/위치·조건 관계, 비용 미측정·시간 비교 한계, 재출력 차단/배포물 회수·게이트별 보류를 함께 판단하도록 했다.

각 단원 3개 총 9개 질문·해설과 활동 피드백, 정확한 실행 위치/명령·예상/관찰/제출을 추가했다. 새 도구는 고정 HTTP/현재 형식 처리·과거 기록 읽기를 구분한다. 최종 평가의 과거 54/70·미작성 16개 문구는 현재 초안 작성/설명 정비와 혼동되지 않게 고쳤다. 과거 보고서/관측값은 그대로 보존했다. Phase1의 설명 깊이·예제/실습 연결을 참고하는 현재 제작 프롬프트를 적용했다.

## 실제 실행·관찰

현재 Router 32개·HTTP/SSE 11개·좁은 DOCX 23개 Python 검사와 Node 공통 Parser/상태 34개가 통과했다. React 고정 버전 빌드도 통과했다. 새 활동의 실행 블록 5개를 확인했다. 메모리 Response에서 한 바이트씩 수신해 final 있음은 completed, 없음은 missing_final/answer=null임을 확인했다. 문서의 전경 서버 명령도 직접 시작해 loopback GET 후 SIGINT 종료했다.

현재 Provider 고정 HTTP 4요청의 최종 상태·호출/예약·판정 순서가 기존 기록과 같았다. 실제 모델 Token·청구 사용량이 아니다. 현재 PDF/TXT/DOCX의 전체 IR과 세 Claim 명세가 저장 기록과 같았고 DOCX 제한 후 과거 출력 승인 거부를 확인했다. 저장된 v2 보고서의 21문단·검토 해시가 기존 DOCX/직접 PDF 내용과 대응했다. 새 DOCX/PDF 생성·DOCX 렌더링을 실행한 것은 아니다.

## 브라우저 화면에서 발견한 환경 차이

실제 Chromium 9사례는 정상·오류·중간 종료·기능 거부·시간 한도·취소/접수·늦은 접수 뒤 재실행·HTML 문자열·390px 크기를 확인했다. 첫 실행은 DOM 상태가 모두 통과했지만 스크린샷의 한글이 네모였다. 상태 검사 통과를 화면 통과로 보고하지 않았다.

기존 실습의 Noto Sans KR 파일이 캐시에 있어 gold의 SHA256과 대조한 뒤 작업용 Fontconfig에 연결했다. 제품/UI 코드를 바꾸거나 새 폰트를 내려받지 않았다. 브라우저를 다시 시작해 같은 9사례를 통과했고 데스크톱 완료/취소·모바일 크기 PNG에서 한글·상태/부분 문장·가로 배치를 직접 확인했다. 두 번 실행한 것을 18종 시나리오로 세지 않는다. 화면 안내에 실제 선택 글꼴/시각 검토 기준을 추가했다. 실제 휴대전화·Safari/Firefox·독립 접근성/수업 평가는 아니다.

## 보존·한계·다음

기존 Router/서버/Parser/React·문서 추출/Registry/검토/출력 코드, lock·원본/과거 결과를 보존했다. 앞 세 단원의 L9 실습도 원문 그대로다. 새 읽기/시연 도구와 설명·안내만 추가/수정했다. 보조 Python 3.12.14/Pydantic 2.14.1은 고정 요구 2.14.2와 다르다. 실제 모델/Tokenizer/유료 Provider·모델 Token Streaming/강제 중단·한글 OCR·새 보고서/일반 문서 벤치마크·실제 인증/운영 Proxy/부하·독립 품질/교실은 미실행이다.

직접 검사 프로세스는 loopback만 허용하는 연결 가드 아래서 외부 연결 시도가 없었다. CLI/브라우저 자식 전체의 OS 격리 증거는 아니다. 현재 실행과 저장 대조·환경 차이·미실행은 [검증 기록](validation.json)에 남겼다. 기존 운영/모델/수업 채택 보류를 유지한다.

다음은 시작 안내 세 단원이다. **추천 추론 강도는 Medium**이다. 범위가 정해진 안내를 기존 실습의 구체적 상황·학습 목표·책임 판단과 연결하는 설명 정비이며 기존 코드·평가 근거를 이어 사용한다.
