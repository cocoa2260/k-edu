이번에 읽을 파일은 [시작 안내 강의](../../lessons/orientation/lesson.md)다. 교육생은 [활동지](../../lessons/orientation/worksheet.md)를 작성한다. [강사용 해설·검토 기준](../../lessons/orientation/teacher-guide.md)은 선택 참고이며 코드나 JSON을 선행해서 읽을 필요가 없다. 제작 순서와 수강 순서는 다르다. 이 안내는 교육생이 K2-01보다 먼저 읽는 강의다.

## 확인한 것과 남은 것

단원 ID·설계 성과·제출물의 연결, 상대 링크, JSON 기록, 57/70 집계, 사람이 읽는 새 Markdown의 코드 블록 부재를 검사했다. 합성 규정 카드에 비추어 실패 사례의 기대 행동, 활동지와 강사 기준의 일치, 분류 축과 날짜를 같은 제작 세션에서 검토했다. 논문·공식 안내는 2026-11-02에 확인했다. 검토의 구체적인 범위는 [validation.json](validation.json)에 기록했다.

새 소프트웨어·모델·출력 기능을 바꾸지 않은 설명 자료 작업이다. 이번에 모델 호출·코드 실행 실습·기존 회귀 테스트를 수행하지 않았다. 강의의 ‘합성 질문 12개에서 금지 실패 0건’은 학생이 기준을 세워보는 예시이며, 이번에 12개 질문을 실행해 달성한 성적이 아니다.

실제 학습자의 이해도·소요 시간·독립 강사의 판정 일치·교육장 수업은 미검증이다. 기존 QLoRA·학습 품질, RAG/Agent의 업무 품질, Framework/MCP, 일반 문서/Vision·실제 모델/수업·운영 채택 게이트도 그대로 남아 있다. 이전 보고서와 코드·자료는 보존한다.
