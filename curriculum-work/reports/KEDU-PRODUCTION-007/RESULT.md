# Single-Agent / L5 제작·검증 결과

**4개 단원과 L5 Runtime을 작성했다. 실제 모델의 Tool 요청 → Registry 실행과 유한 종료를 확인했고 과제 해결·답변 품질은 채택 보류다.** 누적 자료는 70개 중 32개이며 품질·수업 검증 완료 수가 아니다.

[강의](../../lessons/single-agent/lesson.md) → [실제 선택·종료 검토](REVIEW.md)를 보면 된다. 사람이 JSON 전체를 읽어야 결과를 이해하는 구조로 만들지 않았다.

## 실제 모델 실행

같은 core-v1 12개와 새 agent-v1 6개를 고정해 18개를 실행했다. 실제 모델 생성 60회, 도구 처리 시도 46회, 함수 dispatch 46회다. 도구 시도에는 검사 거부와 재시도가 포함되고, 상한에서 처리되지 않은 추가 모델 요청은 포함하지 않는다.

| 실제 종료 이유 | 사례 수 |
|---|---|
| direct_response | 1 |
| input_rejected | 1 |
| repeated_failure | 2 |
| tool_limit | 14 |

함수별 dispatch는 read_evidence 4회, search_documents 42회다. 실제 모델이 검색 요청을 출력하고 Runtime이 E5 검색을 호출하는 경로를 확인했다. 최종 근거 초안은 0개다. 도구를 불렀다는 사실을 원문 확인·정답·과제 완료로 바꾸지 않는다. 사례별 실제 선택과 남은 실패는 REVIEW.md에 보존했다.

처음의 한국어 형식 지시에서는 형식/직접 응답 오류가 나왔다. 이후 상태별 형식 예시와 영어 제어 지시를 사용했다. 읽기 예시에 검색된 첫 Source ID를 넣는 가이드가 있어 독립적인 계획 능력의 증거는 아니다. 준비 실행 7회는 별도 보존했고 통제된 품질 비교로 표시하지 않는다. L4의 잘못된 금액·무관한 근거 문제는 여전히 미완료다.

## 경계·Framework 검증

고정 응답 8개 실험에서 검색→읽기→최종 초안, 불필요 Tool 없는 응답, 없는 이름·승인 위조·승인 없는 저장 거부, 일시 오류 한 번 재시도, 반복 호출 상한을 실제 실행했다. 고정 응답은 학습된 모델의 선택 결과가 아니며 실제 모델 품질에 합산하지 않는다.

모의 저장은 실행 ID·도구·인수에 연결된 신뢰 측 승인 값으로 메모리 안에서 한 번만 허용하고 재사용을 거부했다. 외부 작업·실제 인증·승인 UI·프로세스 간 지속 권한은 구현하지 않았다. 보호 동작의 자동 재시도는 금지한다.

LangChain Core 1.7.3의 StructuredTool invoke를 같은 Registry에 연결해 검색 결과 일치·원문 읽기·추가 인수 거부를 확인했다. 원격 추적을 끄고 requests 가드에서 HTTP 시도 0회였다. 이것은 Tool 연결 검사이며 Framework Agent Loop·MCP 서버/클라이언트/전송을 실행한 것은 아니다. MCP 공식 현재 안내는 2026-07-28 명세로 확인했다.

기존 184개와 새 30개를 합쳐 214개 테스트를 통과했다. 잘못된 이름/인수·발견하지 않은 출처·갱신 후 무효화·승인 위조·반복·재시도·시간/취소·늦은 결과 폐기와 Framework 연결을 검사했다. 테스트의 비의미 벡터와 실제 E5 모델 경로는 구분했다.

## 환경·해석 한계

별도 Linux Python 3.12 CPU 환경을 만들었다. 검색 E5-small과 생성 Qwen3-0.6B의 리비전은 L3/L4와 같다. 모델 결정 4회·도구 처리 3회·읽기 재시도 실행 전체 1회·오류 ID별 반복 2회·180초 전후 검사라는 제한을 둔다. 생성은 입력 1536 Token, 출력 최대 192 Token이며 2000문자 제한도 적용한다. 긴 출력의 잘림도 실패로 기록한다.

180초는 진행 중 요청을 강제로 중단하는 보장이 아니다. 시간값은 이 작은 실험의 관찰이고 교육장 처리량이 아니다. staff·A01 대화 허용은 교사 정의 학습 정책으로 실제 신원 인증이 아니다. MCP 연결·운영 승인·UI·다른 운영체제·GTX 1060 3GB·독립 강사/교육생 검증은 미실행이다.

캐시 재실행은 [offline-check.json](offline-check.json)에 있다. 준비·본 실험·재실행을 합친 로컬 생성은 68회이고 유료 API는 0회다. 캐시/요청 가드는 OS 네트워크 격리 증거가 아니다.

다음은 K2-11/L6 역할 분리·Handoff이며 추천 추론 강도는 High다. 같은 18개 사례와 자료·모델 설정을 재사용하고 역할별 권한과 전체 상한을 지켜야 한다. 모델의 과제 완료·L4 답변 품질은 별도 미완료로 유지한다.
