## 설명과 활동의 보완

기존 두 화면·메뉴 역할·파일 표·두 모델 비교·명령/실제 관찰·오류 안내를 보존했다. 교육생 상단의 관리 단원/제작 코드는 교사용 매핑으로 옮겼다. 목적→모델 후보→Card→Files→실행 예제→Tokenizer Docs의 읽는 순서를 풀었다. 현재 공개 페이지의 Files라는 텍스트와 예전 Files and versions 캡처는 같은 역할로 연결하되 최신 캡처로 바꿔 표시하지 않는다.

Smol 고정 리비전의 영어 중심 한계에서 ‘한국어 업무 추가 확인 후보’라는 판단과 실제 한국어 규정 시험 계획으로 이어지는 완성 예를 추가했다. 영어 중심을 한국어 절대 불가능으로, Instruct라는 이름을 업무 채택으로 확대하지 않는다. 현재 main과 고정 실습 revision을 구분한다.

원문→encode ID 목록→decode 복원문의 부분 코드를 본문에서 설명했다. standalone 코드가 아님을 명시하고 기존 실제 실행 명령으로 연결했다. 저장된 KO30문자/16Token·첫 세 ID,SHORT내용2/패딩14를 풀어 해석하고, 별도 짧은 시연 문장의 숫자와 같다고 요구하지 않는다. Chat Template은 입력이며 모델 답변이 아님을 유지했다. 구간별3개 총9개 질문·판단 근거 해설·답안 칸/피드백을 연결했다.

## 현재 실행과 과거 관찰 대조

부모 커밋의 문서/코드/설정/관찰21개를 Git blob 해시로 대조했다. 현재 제작 프롬프트와 전수 검사에서 정한 보완 범위를 적용하고 이미 확인한 Phase1의 설명/예제/활동 기준을 재사용했다.

현재 Python3.12.14의 preflight는 직접 의존성 네 개가 없어 setup_required·종료코드2였다. 네트워크를 사용하거나 Tokenizer를 로드하지 않았고 새 observations도 만들지 않았다. 이 준비 필요를 실행 성공으로 기록하지 않는다. 의존성 설치/새 Tokenizer·캐시 실행은 이번에 수행하지 않았다.

기존 계약·저장 관찰 회귀17개를 실행해 모두 통과했고 skip은 없었다. 일부 입력/오류 검사는 코드에 명시한 mock을 사용하며 실제 Tokenizer를 대신한 관찰로 쓰지 않는다. 과거 실제 Qwen길이8/16·Smol길이8의 세 관찰을 현재 검사 함수로 다시 읽고 고정 입력 해시·문장/메시지·모델ID/revision·Template옵션과 대조했다.16/13/2·64/13/2 및 현재 교안에 표시한 일부 ID/패딩 수가 일치했다. 이 검사는 저장 기록의 일관성이며 현재 캐시 파일 전체나 새 실행을 검증한 것이 아니다.

2026-11-03에 공식 Docs·두 모델 페이지/Card/Files·Model Card안내와 실습에 고정된 Transformers4.57.1 Tokenizer/Chat Template 문서의 관련 텍스트를 확인했다. 기존 화면 JPG두 장은 게시 경로/원본blob을 보존했으나 도구의 바이너리 응답 제한으로 이번에 이미지를 새로 열어 시각 검토하지 않았다. 현재 화면 촬영·렌더링 검증을 했다고 주장하지 않는다. 화면과 캡처 날짜·기능 역할을 구분하는 안내를 유지했다.

## 보존·검수 범위와 다음

기존 실행 코드·inputs/models/requirements·과거 관찰과 화면·이전 보고서를 수정하지 않았다.17개 검사는 설명 품질의 자동 점수가 아니며 같은 작성자가 본문·활동·질문/해설의 연결과 기술 범위를 따로 검토했다. 상대 링크·코드 블록·표·70개 집계와 runtime/품질 게이트 보존은 정적 검사로 보조한다. 강의의 부분 코드는 현재 API 호출 의미/입력/기록을 대조했으며 새 Tokenizer로 실행한 코드는 아니다.

독립 수업·교육생 장비/동시 실행·실제 생성/훈련/업무 품질은 미검증으로 유지한다. 이번 추천은 High였다. 다음은 전체 수강 흐름에서 교안·선수 준비·누적 실습·제출/해설의 연결을 점검하고 남은 검증의 우선순위/준비 조건을 정리한다. 여러 과목과 증거 범위를 교차 대조해야 하므로 High를 추천한다. [검증 상세](validation.json)를 함께 남긴다.
