# 기존 교육자료·연결 실습 검사 결과

**70개 단원의 본문과 연결 활동지·실습 안내를 읽고 수정 범위를 정했다. 다음은 Prompt 강의와 입력 비교 실습을 대표본으로 수정하는 일이다.** 이번에는 교안·코드·데이터를 수정하지 않았다. 파일 작성 70/70을 설명 품질이나 수업 준비 완료로 보지 않는다.

Phase1은 설명의 깊이와 예제·실습의 연결을 참고하는 기준으로 적용했다. 임의의 요약본으로 만드는 방향은 채택하지 않는다.

| 검사 결과 | 수정 방향 |
|---|---|
| 시작 안내·데이터/평가·Transformer·LLM 기초에는 풀어쓴 사례·계산과 활동지·해설이 있다 | 기존 전개와 계산을 살리고 관리 코드·제작 상태·과목 연결을 정리한다 |
| Hugging Face에는 실제 화면·탐색 활동·Tokenizer 실행/해석 경로가 있다 | 화면과 도구를 살리고 Card 판단 완성 예와 핵심 코드 설명을 보강한다 |
| Prompt·Context는 짧은 설명에서 바로 비교·분류 지시로 넘어간다 | 실제 질문·원문·입력 전후·결과 해석과 개념별 질문/해설을 먼저 완성한다 |
| 후속 Harness·검색·RAG·Agent·학습·문서 강의는 살릴 구현/관찰이 있지만 완성 예·핵심 코드 해설·첫 실행 연결이 부족한 부분이 있다 | 단원마다 빠진 부분을 보강한다. 기존 코드·데이터·검증을 일괄 재작성하지 않는다 |
| 과거 제작 상태가 현재 교안/실습 안내에 남아 있다 | DOCX 지원, 초기/전체 데이터 학습, 마지막 단원의 54/70·다음 제작 안내를 현재 수업 흐름에 맞춘다 |

단원별 문제 위치·수정 방향·재사용 자산·필요 재검증은 **[상세 검사표](REVIEW.md)**에 정리했다. 본문 21개 파일이 70개 단원을 담고 있어 70개 파일을 따로 검사한 것은 아니다. 연결 안내·활동지·해설 등 25개 문서도 포함했다.

**다음 작업:** Prompt 네 단원과 연결 입력 비교 실습을 먼저 수정·재검수한다. 필요한 설명용 코드/JSON에는 맥락과 해석을 붙이고, 관리 식별자는 별도 매핑에 둔다. 대표본의 설명·실습 결함을 해결한 뒤 해당 방식을 후속 과목에 적용한다. 추천 추론 강도는 **High**다. 수정 기준과 대상이 정해져 있으며 설명·예제의 일관성을 깊이 확인할 작업이기 때문이다.

이번 결과는 같은 작성자의 문서 검수와 선택한 코드 부분의 정적 대조다. 구현 전체 재감사·모델/훈련/브라우저 재실행·이미지/문서 재렌더링·독립 강사/교육생 수업은 수행하지 않았다. 실제 모델 품질·QLoRA·교육장/통합 검증의 기존 미완료는 유지한다. 새 기준에서는 70개 모두 보완 필요로 기록하며, 기초 자료의 설명을 전부 다시 쓰라는 판정은 아니다.
