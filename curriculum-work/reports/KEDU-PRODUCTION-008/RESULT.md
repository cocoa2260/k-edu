# Multi-Agent / L6 제작·검증 결과

**K2-11 네 단원·역할 Runtime·전달/예산 검사를 작성했다. 실제 세 역할의 호출은 확인했지만 최종 답변 품질은 채택 보류다.** 누적 70개 중 36개 자료 작성이며 수업 완료 수가 아니다.

[강의](../../lessons/multi-agent/lesson.md) → [실제 비교 검토](REVIEW.md)에서 필요한 사례만 펼치면 된다. 실행은 [L6 실습](../../practice/document-assistant/L6.md)을 본다.

## 실제 실행에서 확인한 것

같은 core-v1 12개·agent-v1 6개를 그대로 사용했다. 같은 E5-small·Qwen3-0.6B 리비전, CPU float32·2 Thread·greedy·non-thinking·출력 최대 192 Token이다. 실행 예시가 있는 Prompt이므로 독립 계획 능력의 입증은 아니다.

| 종료 | 사례 수 |
|---|---|
| 되묻기 | 11 |
| 공백 입력 거부 | 1 |
| 검토 기각 | 6 |

본 실험 모델 생성 42회·도구 처리 14회·함수 진입 14회다. 작성/검토 도달 사례는 C07, C11, A02, A03, A04, A05이며 최종 전달 초안은 0개다. 반복 질문·조기 중단으로 호출이 줄어든 것을 효율 개선으로 채택하지 않는다. C07은 공격 메모, C11은 현행 규정을 읽은 뒤 작성 보류·검토 기각으로 끝났다. 금액 교정 과제를 해결하지 못했고 검토 의견의 정확성도 승인하지 않았다.

작성 도달 사례는 모두 형식 예시와 같은 자료 부족 초안을 냈고, 검토도 예시와 같은 기각 문장을 냈다. 형식을 맞춘 출력과 근거에 따른 판단 능력을 구분해야 한다. 별도 역할 Probe도 같은 보류/기각 행동이므로 정답 작성 능력의 성공 증거가 아니다.

Single은 모델 4회·도구 3회·180초, Multi는 전체 모델 8회·도구 6회·240초와 역할별 4/2/3회다. Prompt와 예산 차이를 밝히며 역할 수 하나의 효과로 결론 내리지 않는다. 비교표의 처리 시간은 모델 적재를 제외한 한 번의 CPU 관찰이고 13개는 중단 전, 5개는 재개 후 실행했다. L5 별도 적재 시간과 최초 L6 적재 시간은 미상이다. 마지막 재개 초기화만 기록했고 다운로드 시간도 포함하므로 순수 모델 적재 벤치마크로 비교하지 않는다.

## 전달·보완·종료 경계

Runtime이 실행/질문/역할 ID·현재 원문·수신 범위·누적 예산을 확인한다. 자유 요약 대신 읽은 근거 ID와 고정 부족 정보 코드를 넘긴다. 작성/검토의 원문 읽기는 전달받은 ID로 제한하며 역할이 바뀌어도 전역 예산을 유지한다. 작성자의 근거 요청과 검토자의 보완은 같은 1회 예산을 쓴다.

고정 응답 Control·별도 M01~M04로 수신 범위 거부, 추가 근거 요청, 같은 검토 실패 반복, 전체 호출·일시 오류·시간 종료를 검사했다. 실제 모델 품질 분모에 넣지 않는다. 기존 214개와 신규 29개를 합쳐 **243개 테스트 통과**다. 모델 pass도 사용자 승인이나 의미적 정답을 뜻하지 않고 사람이 검토할 초안으로 남긴다.

실험 초기에 JSON을 Markdown으로 감싼 출력이 파서에서 거부됐다. 응답 전체가 정확히 하나의 JSON 블록일 때만 포장을 벗기고 동일 Schema를 적용했다. Python이나 앞뒤 설명·여러 JSON은 추출/실행하지 않는다. 준비 실행은 별도 보존했고 통제된 품질 비교로 사용하지 않았다.

## 실행 범위와 다음 작업

개별 역할 확인 2회·준비 3회·캐시 재실행 1회를 더한 실제 로컬 생성은 48회, 유료 API 0회다. Role Probe는 Runtime이 근거를 준비한 별도 실행이며 통합 성공이 아니다. 중단 후 모델 캐시가 없어 같은 리비전을 다시 받았고, 13개 체크포인트를 재생성하지 않고 이어갔다.

캐시 재실행은 requests 가드 안에서 확인했고 OS 네트워크 격리 검사가 아니다. 기존 웹 API·academy 원문·과거 보고서·원본 자료는 유지했다. 모델 가중치·SQLite는 Git에 넣지 않는다. Framework Agent 전체·MCP·실제 인증/지속 승인·UI·독립 수업·교육장 동시 처리량은 미검증이다. L4/L5/L6 모델 과제와 답변 품질은 미완료로 유지한다.

다음은 K2-12.U01~U04의 PEFT 전략·Dataset 제작/분리·증강·학습 입력 검증이다. 추천 추론 강도는 **High**다. 실제 LoRA 훈련·QLoRA 자원 검사·새 프로세스 Reload는 뒤의 U05~U08에서 별도 실행하며 이번에 완료했다고 표시하지 않는다. 남은 기초·안내 단원도 전체 완료 전에 작성한다.
