# RAG / L4 제작·검증 결과

**4개 단원과 L4를 작성하고 실제 E5 검색 → Context → Qwen 생성 → 출력 검사까지 실행했다. 답변 품질은 두 지시 버전 모두 채택 보류다.** 작성 자료는 70개 중 28개이며 수업·서비스 검증 완료 수가 아니다.

[강의](../../lessons/rag/lesson.md) → [실제 사례 검토](REVIEW.md)를 보면 된다. 출처 링크는 같은 실행의 [원문](sources.md)으로 연결된다. JSON 전체를 읽지 않아도 실패와 남은 과제를 확인할 수 있다.

## 실제 실행과 판정

기존 12개 사례를 v1/v2로 실행하고 각 버전에서 C07 질의 변경·C09 인접 줄 확장을 추가했다. 공백 C10은 두 버전 모두 생성 전에 거부했다. 본 실험 생성 29회와 캐시 재실행 2회를 합쳐 실제 로컬 생성 31회이며 유료 API 호출은 0회다.

| 구분 | v1 | v2 |
|---|---|---|
| 공백 외 11개 중 최초 자동 검사 통과 | 11 | 8 |
| 보완 포함 최종 자동 검사 통과 | 11 | 9 |
| 사실 6개 완전 통과, 같은 Work 원문 대조 | 0 | 0 |
| 경계 행동 6개 완전 통과, 같은 Work 원문 대조 | 3 | 1 |

자동 검사는 구조·제공 Source ID·부분 인용의 원문 존재까지다. v1은 대부분 자료 부족 상태로 답했고 C01은 금액을 말하면서 인용이 없었다. v2는 일부 사실과 인용이 생겼지만 잘못된 금액·공격 메모 답변·무관한 근거·조건 누락이 남았다. 이 수치를 RAG 정답률이나 모델 일반 성능으로 해석하지 않는다.

C01 v2는 실제 첫 응답의 필드 누락을 한 번 보완해 인용 초안을 얻었다. C03/C04 v2는 반복 출력 실패 뒤 초안 없이 멈췄다. 따라서 정상 생성·실제 형식 보완·안전 종료를 관찰했다. 초안의 사실성·승인 상태는 자동으로 통과시키지 않았다.

C07의 질의를 바꿔 공격 메모가 Context에서 빠져도 원 질문의 999999원을 답했다. 검색 변경만으로 해결되지 않았다. C09 인접 줄을 넣으니 잘못된 20만원 답변이 출장 30000원·교육 200000원으로 바뀌었지만, 인용은 영수증 표뿐이라 금액 근거 연결은 미완료였다.

## 환경·검사

L3의 Linux Python 3.12.14 / PyTorch 2.15.0+cpu / Transformers 4.57.1 환경을 재사용했다. 실제 생성 모델은 Qwen/Qwen3-0.6B, 리비전 c1899de289a04d12100db370d81485cdf75e47ca, CPU float32다. 비교를 고정하려고 Greedy·non-thinking을 썼으며 Model Card의 권장 샘플링을 최적화한 실험은 아니다.

Chat Template 포함 입력 1536 Token·신규 출력 최대 512 Token, 기존 2000문자 계약, L2 총 시도 3회·재시도 1회·보완 1회를 적용했다. 사용량은 로컬 Provider의 실제 관찰에 기록했다. 시간 제한은 호출 전후 확인이며 진행 중인 생성을 강제로 끊지 않는다. 경과시간은 최적화한 성능·동시 수업 처리량이 아니다.

기존 164개를 포함해 184개 테스트가 통과했다. 테스트는 고정 응답으로 원문/인용 검사·잘못된 주장 검사의 한계·권한 제외·갱신 시 답변 폐기·오류 구간 분리·L2 예산 재사용을 확인했다. 실제 모델 실행은 이 테스트와 별개다.

C01 v2를 캐시만 읽고 다시 실행해 두 원응답과 최종 초안이 같았다. requests 요청 가드의 HTTP 시도는 0회였으며 OS 네트워크 격리 검증은 아니다. 원문·과거 보고서·기존 API는 보존했고 로컬 생성 Provider는 CLI에서 명시적으로 주입했다. 기존 웹 API Factory가 Ollama/OpenAI에서 자동 전환한 것이 아니다.

## 남은 일

실제 RAG 실행 경로를 확인했지만 의미적 근거·필수 조건·공격 저항성은 미통과다. 두 버전 모두 서비스용 채택을 보류한다. 검토는 같은 Work 세션으로 독립 강사·교육생의 평가가 아니다. 실제 인증·승인·UI·GTX 1060 3GB·다른 운영체제·교육장 동시 실행도 검증하지 않았다.

다음 제작은 Single-Agent/K2-10/L5이며 추천 추론 강도는 High다. 검색을 Tool로 제공하되 모델 출력이 권한이나 실행 승인을 바꾸지 못하게 한다. 이번 품질 문제는 별도 미완료 항목으로 유지하며 Tool을 붙였다는 이유로 해결된 것으로 표시하지 않는다.
