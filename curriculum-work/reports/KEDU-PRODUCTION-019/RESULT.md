## 실행해서 확인한 범위

외부 의존성이 없는 [예제 검사기](../../practice/data-evaluation/check_examples.py)로 원본 12그룹/24행의 알려진 계보 분리와 수량·Label을 확인했다. 별도의 20행 Dev 가상 점수에서 기준선과 임계값 두 개를 재계산하여 강의·강사 해설의 수치와 대조했다.

| 가상 점수의 결정 | TP / FP / FN / TN | Accuracy | Recall | F1 | 예시 영향 합계 10FN+FP |
|---|---|---|---|---|---|
| 항상 0 | 0 / 0 / 4 / 16 | 80% | 0% | 0% | 40 |
| 임계값 0.70 | 2 / 1 / 2 / 15 | 85% | 50% | 57.1% | 21 |
| 임계값 0.30 | 4 / 4 / 0 / 12 | 80% | 100% | 66.7% | 4 |

같은 부모의 변형을 Test로 이동, 변형 Label 모순, ID 중복, Label 범위 오류, 점수 범위/비유한 값 오류, Dev를 Test로 잘못 표시, 가상 점수를 모델 결과로 잘못 표시한 **8개 변조 반례를 검출**했다. 분모 0일 때 미정의로 남기는 계산도 확인했다. 이는 고정 합성 자료·계산의 검사이며 분류기나 상담 시스템의 성능 검증이 아니다.

네 단원의 성과/제출물 연결, 새 문서와 진행 문서의 상대 링크·JSON·61/70 집계·사람용 Markdown의 코드 블록 부재를 확인했다. Label의 업무 의미·활동지/해설 일치·분류 지표와 권한/금지 행동의 분리를 같은 제작 세션에서 검토했다. 기록·자료 해시는 [validation.json](validation.json)에 있다.

## 하지 않은 검증과 남은 작업

가상 점수는 제작자가 계산 연습용으로 부여했다. 모델 추론·훈련·모델 증강·Test 성능 평가는 실행하지 않았다. 원본 계보가 분리되어도 G05/G11 같은 의미상 유사 질문이 남는 한계를 강의·카드·검사 결과에 표시했다. 새 문서 일반화나 의미 중복 제거 성능도 입증하지 않았다.

이전 앱·모델·훈련 코드를 수정하지 않아 기존 회귀 테스트는 다시 실행하지 않았다. 독립 라벨 검토·학습 시간/이해도·독립 강사 검토·교육장 수업, 기존 QLoRA·학습/답변 품질·Framework/MCP·실제 운영 채택 게이트는 미완료로 유지한다. 이전 기록과 원문·예제는 보존한다.
