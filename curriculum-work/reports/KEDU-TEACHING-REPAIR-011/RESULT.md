# Fine-tuning 데이터 준비 교안·실습 수정

**앞 네 단원과 연결 데이터 준비 활동을 수정하고 같은 작성자가 설명·예제·코드를 재검수했다.** 독립 수업 검증은 아니다. 누적 37개 설명 검수와 나머지 33개 정비·모델 품질/수업 게이트를 구분한다.

[강의](../../lessons/fine-tuning/lesson.md) · [실습](../../practice/document-assistant/L7.md) · [강사용 해설](../../lessons/fine-tuning/teacher-guide.md)

## 설명 흐름과 수정 이유

기존 목표/방법·표/제출물 지시를 회의실 규정 한 가족에서 풀어 설명했다. 근거가 있는데 보류하는 문제에서 시작해 SFT 목표와 LoRA 등 변경 방법의 축을 구분하고, 답변·전제 교정·되묻기·보류·거부의 다섯 정답이 왜 필요한지 연결했다. PEFT 계열의 기존 범위는 지도와 선택 기준으로 유지했다. Adapter 이름을 외워야 다음으로 갈 수 있게 만들지 않았다.

원문·훈련 예제·평가 문항, 가족 4/2/2와 원본 20/10/10, Train 증강 뒤 28/10/10을 설명했다. 부모/파생·권한/정답 유지와 네 기각 이유, 동일 작성자 고정 예제·리뷰 해시/문자열 인용의 한계를 포함했다. messages에서 관리 메타데이터를 빼는 이유와 실제 Prefix/정답/EOS·Padding·한 번의 Causal shift를 연결했다. 12개 개념별 질문·해설과 네 필수 활동·선택적 실제 변환/후속 훈련을 제공한다.

기존 L7에는 준비 단계의 ‘학습기를 구현하지 않았다’와 나중 실제 훈련 기록이 섞여 있었다. 준비 도구가 학습하지 않는다는 사실과 이후 수행한 훈련을 구분하고, 기존 소규모/전체 Train·재로드/회귀 안내는 그대로 보존했다. 후반 훈련 네 단원은 다음 정비 범위다.

## 실제 확인한 범위

보조 Python 3.12.14/Pydantic 2.14.1에서 현재 검수 함수로 원본 40개와 후보 12개를 처리해 8개 채택/4개 기각과 18개 기존 회귀 질문 제외를 확인했다. 가족 분리·원문 버전·내용 변경/검수 해시·거부 원문 유출·회귀 질문 유입 경계를 검사했다. 모든 48행의 messages 역할·학습 내용과 메타데이터 분리를 확인했다. 올바른 인용을 유지하면서 답만 20시간으로 바꾸어도 행 수준 인용 검사는 통과할 수 있어 의미 검수의 필요성도 대조했다. 기존 리뷰는 내용 변경을 거부했다.

과거 실제 Tokenizer 저장 기록의 첫 예제 messages가 현재 코드와 같고 전체 357·Prefix 250·정답/EOS 106과 정답 위치 250~355, 저장 복원 문자열이 교사 JSON+EOS임을 확인했다. 실제 저장 Batch의 Padding 149곳은 -100이며 실제 EOS 두 개는 정답에 남는다. 이는 저장값의 무결성·경계 대조이며 새 Tokenizer/decode 실행이 아니다. 실습의 새 Bash 블록 네 개, 가상 Token Padding, 읽기 도구 원본 40개·잘못된 인자 두 유형을 실행했다.

고정 요구 Pydantic 2.14.2와 다른 보조 환경이다. 새 Tokenizer/Datasets/Arrow·모델 추론·Optimizer·Torch 수치 검사·전체 Pytest/HTTP·QLoRA·독립 수업/품질은 미실행이다. 직접 검사 프로세스에서 연결 시도는 없었으며 OS 네트워크 격리 검증은 아니다. 코드 검사/문서 검수를 모델 품질이나 교육장 실행 완료로 표시하지 않는다.

## 보존과 다음

현재 검수/변환 코드·원본 자료·과거 보고서와 후속 훈련 안내 원문을 보존했다. 새 도구는 로컬 읽기 전용이며 검수 승인·모델 호출·파일 출력을 하지 않는다. 변경 파일·원본 버전과 검증 범위는 [검증 기록](validation.json)에 남긴다. Phase1의 설명 깊이·예제/실습 연결과 현재 제작 프롬프트의 기준을 적용했다.

다음은 LoRA 원리/설정, QLoRA 자원 조건, 동일 기준 평가, Adapter 저장/재로드의 네 단원과 L7 후속 훈련 안내다. **추천 추론 강도: High.** 실제 Parameter·Gradient·Step과 원본/증강 비교를 연결하고 과거 실행·현재 한계·미실행을 구별해야 한다.
