# Prompt 대표 교안·연결 실습 수정 결과

**Prompt 네 단원과 연결 실습을 수정하고 같은 작성자의 설명 검수를 마쳤다.** Phase1에서 참고한 상황→설명→예제→실행/관찰→해석의 흐름을 적용했다. 다음 정비 대상은 Context 네 단원과 직접 연결된 실습이다. 다른 66개 단원을 이번에 수정한 것은 아니다.

먼저 볼 자료는 **[수정한 강의](../../lessons/prompt/lesson.md)**다. 학생은 **[연결 실습](../../practice/document-assistant/L1.md)**으로 이어간다. **[강사용 해설](../../lessons/prompt/teacher-guide.md)**은 개념별 질문과 실습 피드백, 기존 단원 매핑을 담는다. 관리 보고서/JSON은 학생의 필수 읽기 경로에서 제외했다.

| 바뀐 부분 | 구체적인 결과 |
|---|---|
| 최초 설명·완성 예제 | 식비 질문과 실제 규정→상한/조건/예외→작성 지시 전후→불완전/충실 답안의 원문 판정 |
| 시범·코드 | 실제 도서 시범 두 개, 예시 추가 위치, 조립 핵심 코드와 줄별 역할·길이 해석 |
| 실행 전략·평가 | 후보 집계와 도구 요청/관찰의 차이, 식비 개선/숙박비 회귀의 완성 예. 가상 설명과 실제 실행을 구분 |
| 실습 | JSON을 먼저 열지 않는 입력 비교 도구, 지시 한 문장 추가 후 자료/질문 동일성을 확인하는 실행 활동, 관찰/판정 작성 표 |
| 질문·관리 표기 | 각 장의 개념별 질문과 교사 해설. 기존 단원 ID는 교사용 매핑·인덱스에 유지 |

## 확인한 것과 남긴 범위

기존 실제 규정·평가 사례·시범·입력 생성 코드·API·기존 실행 보고서는 보존했다. 새 `tools.prompt_inputs`는 기존 준비 함수를 재사용하는 표시 도구다. 별도 모델이나 복제 앱을 만들지 않았다.

- 전체 60조합에서 **입력 55개 준비·공백 5개 거부**를 재확인했다. 모델 정답률이 아니다.
- 새 도구의 기본 표시, 다섯 조건의 전체 입력, 다른 질문, 없는 사례/공백/잘못된 조건의 종료를 확인했다.
- 본문의 실행 가능한 Python과 실습의 지시 변경 코드를 실제로 실행했다. 변경 입력은 1174문자이고 지시 뒤 자료·질문 부분은 동일했다. 핵심 발췌는 실제 조립 소스와 대조했다.
- 새로 만든 다섯 샘플 파일의 SHA256이 기존 Token 계산에 사용한 입력 파일과 같았다. 본문의 657/723/793과 증가량 66/70은 **기존 Tokenizer 관찰**을 재사용했다. Tokenizer를 새로 실행한 것은 아니다.
- 보조 검사에서 네트워크 연결/주소 조회를 시도하면 중단하도록 감시했고 시도는 0회였다. 새 모델 생성도 0회다.

**현재 보조 실행 환경은 Python 3.12.14/Pydantic 2.14.1**이며 기존 학생용 고정 요구인 Pydantic 2.14.2와 다르다. 이 환경에서 실제 입력/CLI/교안 코드가 동작했다는 증거다. 전체 고정 FastAPI/pytest 환경의 재검증을 완료했다고 표시하지 않는다. 기존 API·계약·입력 생성 코드/자료는 바꾸지 않아 그 범위의 과거 증거는 보존했다.

## 설명 재검수의 판정

이번 판정은 **대표본의 설명·실습 연결에 대한 동일 작성자 문서 검수 통과**다. 학습 맥락, 최초 개념, 예제, 실습/해석, 실제 자료 일치, 개념별 질문·해설, 관리 기록 분리, 증거 수준을 실제 본문/실행과 대조했다. 기준별 근거는 [검증 기록](validation.json)에 남겼다. 파일 길이·코드 검사 개수로 교안 품질을 판정한 것이 아니다.

독립 강사/교육생 수업, 전체 Prompt 조건의 실제 생성/의미 평가, 학생 장비/동시 실행, 기존 RAG·Agent 품질·QLoRA 등은 여전히 미완료다. 이 대표본을 그 검증의 성공 증거로 사용하지 않는다.

**다음 작업은 Context 수정·재검수, 추천 추론 강도는 High**다. 기준·대표본·수정 범위가 정해졌으며, 자료 선택/신뢰/Token 예산/현재 입력 조립의 설명과 실제 동작 연결을 확인해야 한다. 같은 문단 틀을 복제하지 않고 주제에 맞게 적용한다.
