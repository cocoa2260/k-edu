# Embedding 교안·연결 실습 수정 결과

**Embedding 네 단원과 연결 실습의 설명·예제·관찰·해설을 수정하고 같은 작성자가 재검수했다.** 독립 강사/교육생 수업 검증은 아니다. 전체 70개 중 이번까지 이 기준의 설명 검수를 마친 범위는 17개이며 나머지 53개 정비와 별도 품질 게이트는 남아 있다.

[학생 강의](../../lessons/embedding/lesson.md) · [실습](../../practice/document-assistant/L3.md#embedding-활동) · [강사 해설](../../lessons/embedding/teacher-guide.md)

## 수정한 학습 흐름

- 같은 ‘밥값’ 질문에서 ID·입력 벡터·문맥 표현·검색 벡터를 구분하고, 접두어·입력 문자열과 실제 Pooling 핵심 줄을 설명했다. 패딩 제외 평균은 가상 2차원 값으로 먼저 풀었다.
- BM25/Dense의 정의만 제시하던 부분에 현재 분절/어휘 일치, 과거 실제 상위 조각과 원문 조건을 연결했다. C08에서 BM25가 성공한 이유를 ‘당일’ 일치로 확인하고 의미 학습으로 꾸미지 않았다.
- 기존 q/A/B 반례를 보존하고 노름·정규화 전후·거리/제곱 거리의 중간 계산을 추가했다. RRF는 세 후보의 전체 순위로 합산해 보여 주고 실제 전체 후보 결합과 상위3 기록의 차이를 설명했다.
- 공격 메모·기준 없음·문서 회수와 필요한 줄의 차이를 실제 관찰에 연결했다. C09는 두 문서를 찾아도 교육비 상한 줄이 빠져 있어 문서 회수 1.0이 근거 충분성을 보장하지 않는다.
- 개념별 질문 12개와 해설, 연결 활동5개·관찰/오류 안내·교체/복구 계획을 만들었다. 학생 제목은 의미 중심으로 쓰고 관리 단원 매핑은 강사 해설에 유지했다.

## 확인 중 발견한 기록 오류와 수정

기존 `LocalIndex.manifest()`는 `encoder.profile` 사전을 그대로 반환했다. 실행 후반에 같은 모델의 Token 상한을 512에서 128로 바꿀 때 앞서 만든 Manifest 표시값도 바뀌었다. 과거 `retrieval-observed.json`의 변경 전/삭제 후 profile은 128로 보이지만, 당시 `profile_sha256`는 512 설정으로 재계산할 때 일치하고 128에서는 일치하지 않는다. 기존 실행 코드의 기본값도 512다.

수정은 Manifest 반환 시 설정을 깊은 복사하는 것뿐이다. 새 관찰 도구는 과거 불일치를 알리며 원본을 몰래 정정하지 않는다. 과거 JSON·결과 수치·E5 인코더·모델·질문/정답/원본 자료·BM25/Dense/RRF 검색 계산은 보존했다. 표시값의 사후 변경은 검색 순위·점수 목록을 다시 계산하는 동작이 아니다. 이 오류 때문에 과거 profile 표시값만을 최초 실행 설정의 증거로 재사용하지 않는다.

## 이번에 실제로 검사한 것

Python 3.12.14 표준 라이브러리 환경에서 다음을 실행했다. 모델/Transformers/PyTorch/Pytest를 설치하거나 호출하지 않았다.

- 원래 코드로 기록 사후 변경과 반환값 편집의 두 실패를 재현했다. 수정 코드로 설정 독립성 두 방향과 Index 갱신/삭제/오래된 Context 거부를 확인했다. 추가 회귀 명령은 `python -m unittest discover -s embedding_tests -v`다.
- 두 전체 실행 코드 블록의 고정 계산/어휘 결과를 실행했고 인코더 발췌는 원본 코드와 일치했다. A/B 내적·Cosine·단위 제곱 거리, 패딩 제외 평균, RRF 점수와 B→A→C를 검산했다.
- 새 도구의 수치/분절/기록 요약·12개 사례 읽기와 잘못된 명령/경로/사례를 확인했다. 가상 계산/답변 생성 기록을 실제 검색 기록으로 읽지 않게 했다.
- 과거 36조건에서 8개 관련 문서 사례의 회수·첫 문서 적중 지표를 원본 라벨과 다시 계산해 기존 수치와 일치했다. 이 작업은 모델 재실행이 아니라 저장된 관찰값의 재계산이다.
- 제한/구버전 배제·공백 거부, 공격 메모 우선·규정 누락, 두 문서와 필요한 줄의 차이, 과거 설정 표시값/해시 불일치를 기록과 대조했다. 직접 검사 프로세스의 네트워크 가드는 연결 시도를 0회 관찰했다. OS 차원의 격리 검증은 아니다.

## 보존과 한계

L3의 기존 Index 경계·합성 ANN 절과 Index 강의, 기존 테스트·검색 실행 도구/모델 설정·API·데이터·역사 보고서를 보존했다. Index 네 단원의 새 설명 검수는 아직이다. 이전 실제 CPU Embedding 증거는 그대로 연결하되 이번에 실제 모델/캐시 검색·원래 전체 Pytest/HTTP 환경·FAISS·다른 가중치 전환·Reranker·수업을 다시 실행했다고 하지 않는다. 이번 기록 수정은 실제 검색 생성까지 새로 검증한 것이 아니며 다음 새 모델 실행에서 변경 전512/변경 후128과 해시 일치를 관찰할 수 있다.

본문·명령의 정적/선택 실행 검사와 같은 작성자의 설명 검수를 수업 적합성의 독립 증명으로 표시하지 않는다. 세부 기준별 근거와 실행 범위는 [validation.json](validation.json)에 남긴다. QLoRA·전체 실제 과제/의미 품질·교육장 장비/UI/독립 수업과 기존 미완료 게이트도 유지한다.

## 다음 작업

Index 운영 네 단원과 연결 실습을 수정한다. 작은 레코드/원문 추적, Exact/ANN의 차이, 그래프·구역 탐색, 문서 변경→오래된 선택 거부→재검색→삭제를 풀어 설명한다. 추천 추론 강도는 **High**다. 표현/순위 문제와 근사 탐색 누락, 원문과 저장소 시점을 정확히 연결해야 한다.

공식 출처는 [E5 Model Card](https://huggingface.co/intfloat/multilingual-e5-small/blob/main/README.md)와 [연구 보고서](https://arxiv.org/abs/2402.05672)를 확인했다. 이번 검색 도구에서 고정 리비전 Model Card URL은 열리지 않아 현재 공식 카드와 고정 로컬 인코더를 대조했으며, 이를 고정 원문 전체 재확인으로 표시하지 않는다.
