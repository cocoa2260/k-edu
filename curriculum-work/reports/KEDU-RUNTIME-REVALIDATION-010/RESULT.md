# Phase2 실습 검증 종합과 수업 사용 범위

2026년 11월 4일 · 검증 010 · 기준 커밋 `1c1fdb713dff2839eecf8a324a8fa0b080516312`

**가상 자료로 원리를 설명하고, 준비된 환경에서 제한된 실습을 검증하는 파일럿을 진행할 수 있다.** 단원 70개가 작성됐고 동일 작성자의 설명 검수를 거쳤다. 학습자 수업은 70개 단원 모두 미실행으로 기록돼 있다. 이번 문서는 001~009의 실행 근거를 종합하고 파일럿 진행 기준을 만든다. 전체 과정의 수업 채택, 업무 답변 품질, 서비스 운영은 보류다.

- **직접 활동** — 학생이 현재 코드나 자료를 사용해 결과를 만들거나 손계산한다. 고정 입력으로 실행하면 결과에 고정 실험이라고 표시한다.
- **기록 시연** — 이미 저장된 실행 결과를 읽고 무엇을 확인할 수 있는지 설명한다. 학생의 새 실행 실적으로 집계하지 않는다.
- **별도 검증** — 현재 자료의 실행 기록만으로 강의 필수 환경 또는 실제 업무 용도로 채택하기 어려운 항목이다.

## 파일럿 명령 사전 확인

동일 작성자가 네 활동의 명령을 Linux에서 실행했다. 벡터 계산, 잘못된 금액이 형식 검사를 통과하는 고정 실험, 디지털 PDF의 0원·15,000원 행 추출, final이 없는 메모리 SSE에서 확정 답변이 비어 있는 것을 확인했다. 이 점검에는 새 모델 생성, 브라우저 수업, 독립 강사·교육생 참여가 포함되지 않았다. [사전 실행 기록](validation.json)
