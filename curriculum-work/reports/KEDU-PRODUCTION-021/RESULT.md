## 실행해서 확인한 범위

[합성 자료](../../practice/llm-basics/examples.json)와 외부 의존성이 없는 [검사기](../../practice/llm-basics/check_examples.py)로 확률·필터·선택·예시 판정 기록을 확인했다.

| 검사 | 결과 |
|---|---|
| 고정 Logit [2,1,0,-1] | T=1/0.5/2의 확률 합과 기준값 일치. B의 한 위치 손실 약 1.4402 nat |
| Top-k=2·Top-p=0.8 | 이 예시에서는 모두 A/B, 재정규화 약 0.7311/0.2689 |
| 한 설정 변경 | Logit·Token 순서·u=0.70·선택/필터를 고정하고 Temperature만 변경. T=1은 B, T=0.5는 A |
| Greedy와 Beam | 별도 두 단계 트리에서 Greedy AX 0.30, 폭 2 Beam의 최선 BX 0.36 |
| 여섯 합성 응답 | 필수 필드 검사와 작성자가 부여한 내용/근거/안전 판정, 합성 시간 기준을 다섯 축으로 분리해 기록 |
| 미확인·금지 행동 처리 | 미확인을 통과로 올리거나 안전 실패를 평균으로 상쇄하지 않는 예제 판정 규칙 확인 |

Temperature 0·비유한 Logit·잘못된 Top-k/Top-p·추출 조회값 경계·판정 Label·음수 예시 시간의 **8개 잘못된 입력을 거부**했다. Top-p의 누적 경계 Token 포함과 재정규화도 확인했다.

이 실행은 **직접 만든 Logit의 한 단계 Token 선택**이다. 실제 사전학습 모델의 프롬프트 생성 비교가 아니다. 여섯 응답의 내용·근거·안전 판정은 같은 제작자가 작성한 해설이며 코드가 독립적으로 의미를 채점한 것이 아니다. 시간도 실측이 아니다. 이 구분과 실제 생성 비교의 후속 기록 양식을 강의·활동지·강사 기준에 명시했다.

단원 성과/제출물과 강사 기준의 연결, 상대 링크·JSON·70/70 집계·새 사람용 Markdown의 코드 블록 부재를 확인했다. 저장/전달과 자동 학습의 구분, 신뢰할 수 없는 문서 지시와 권한, Token 확률과 사실성의 구분은 같은 제작 세션에서 검토했다. 수치·자료/코드 해시와 세부 범위는 [validation.json](validation.json)에 있다.
