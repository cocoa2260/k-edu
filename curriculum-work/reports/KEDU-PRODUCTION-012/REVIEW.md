# 사람이 확인할 부분

이 문서는 같은 제작 세션의 검토이며 독립 강사·교육생 평가가 아니다. [강의](../../lessons/document-parsing/lesson.md)와 [결과](RESULT.md)만으로 기본 내용을 읽을 수 있다.

| 관찰 | 정답/원본 | 실제 추출/처리 | 판정 |
|---|---|---|---|
| 깨끗한 스캔 제목 | 환불 신청 안내 | 완 불 신청 안내 | 문자 오류. OCR 전체 무검토 채택 보류 |
| 기한 | 결제 후 7일 | 결제 후 7 일 | 값은 발견. 공백 토큰 평가는 달라짐 |
| 금액 | 15000원 | 15000 원 | 문자열 존재 확인. 행·조건 의미는 별도 검토 |
| 접수 번호 | RF-1048 | RF-1048 | 이번 스캔 일치 |
| 열화/흑백화 | 같은 네 줄 | 공백 제외 글자 오류 0, 흑백화 후 지표 동일 | 이 예제에서는 개선 효과 없음. 일반화 보류 |
| 두 열 | 왼쪽 A1·A2 / 오른쪽 B1·B2 | 저장 순서 오른쪽 먼저, 수동 영역 지정으로 분리 | 순서 문제 재현. 자동 Layout 모델 미실행 |
| 표 | 사용 이력 행의 부담금 15000원 | 머리글·3×3 행렬 일치 | 이 표 한 개 통과. 줄 검색의 관계 보존은 미완성 |
| 문서 지시 | 외부 자료 속 Ignore rules 문장 | 문자열 보존, 명령 실행 없음 | Parser 데이터 경계 통과. LLM Injection 저항 미검증 |
| 원문 복귀 | 영수증을 포함한 줄 | 1쪽, 좌상단 기준 (42.00, 123.44)~(459.03, 135.44) point | 줄 전체 영역. 단어 단위 정밀 하이라이트 아님 |
| 기존 Index 경로 | 기존 JSON 기본 경로 | 논리 origin_path가 기본값으로 남음 | 실제 PDF 이동에는 해시 검증한 물리 Locator 기록 사용 |

원문 연결에서 ‘영수증’ 검색은 실패했고 ‘영수증을’로 경계 실험을 수행했다. 어절 기반 검색기의 제한이므로 실제 사용자 검색 품질을 통과시킨 결과가 아니다. 직접 추출의 한 줄에 왼쪽·오른쪽 열이 합쳐지는 제한도 보존했다.

## 교육생 제출물과 강사 확인

| 단원 | 제출물 | 통과 판단 |
|---|---|---|
| U01 | 페이지별 유형·처리 경로·근거 | 혼합 파일을 한 경로로 처리하지 않음. 기존 OCR 층도 원본 대조 |
| U02 | 열 순서 전후 비교·표의 잘못된 관계 예 | 숫자뿐 아니라 행/열 조건을 연결하고 수동 영역 지정의 한계를 설명 |
| U03 | CER·WER·필드·표·순서·답변을 구분한 오류표 | 평균 지표가 작아도 금액 오류·근거 누락이면 검토로 전환 |
| U04 | 문맥에서 원본까지의 연결·변경 후 거부 | 문서 지시가 권한을 바꾸지 않고 삭제/권한/버전 변경 뒤 재검사 |

교육생이 실행 로그를 제출했다는 이유로 의미 판단까지 자동 합격시키지 않는다. 독립 수업 검증에서는 다른 문서로 경로 선택·금액/표 오연결·원문 복귀를 직접 설명하게 하고, 교사가 원본과 대조한다. 이 평가는 아직 실행하지 않았다.
