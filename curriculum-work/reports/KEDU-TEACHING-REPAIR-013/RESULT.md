## 보완이 필요했던 부분과 수정

기존 본문에는 가상 환불 문서·화면과 추출 한계 설명이 있어 보존했다. 다만 단원 관리 코드로 시작했고 직접 활동의 실행 명령/결과 해석·개념별 질문 해설이 부족했다. L8은 CLI 인수를 소스 파일로 넘겼고 ‘본문에 실행 코드·JSON을 섞지 않았다’고 써 코드 종류를 구분하는 현재 작성 기준과 맞지 않았다. 이번에는 실제 실행 블록·저장 출력·설명용 JSON을 목적과 함께 제시했다.

15000원 발견만으로 미사용 고객의 금액을 답할 수 없는 상황에서 시작한다. Parsing/OCR 입력 차이·페이지별 분기와 같은 페이지의 부분 텍스트 한계, 저장/좌표/사람의 순서 차이와 실제 합쳐진 검색 줄, 표의 행·열 관계를 풀었다. 같은 2.5% CER의 제목/금액 오류, 중요 필드와 조건 관계·Confidence의 한계, 시각 모델의 입력/출력 선택도 연결했다. 원문 Locator가 두 열의 줄 전체를 가리키는 실제 반례로 위치 연결과 의미·하이라이트를 구분했다.

각 장 3개 총 12개 질문과 강사용 근거 해설, 네 활동의 예상·실행 위치/준비·관찰/해석·제출을 추가했다. 저장 기록 읽기·현재 직접 추출/지표 계산·선택적 실제 한글 OCR를 구분했다. 기존 PDF/PNG/gold·검수/추출 코드·실행 보고서는 바꾸지 않았다. Phase1의 설명 깊이·예제/실습 연결을 참고하는 현재 제작 프롬프트를 적용했다.

## 현재 실행한 범위

Python 3.12.14에서 PDF 네 개 5쪽의 문자/이미지·직접 텍스트 유무를 확인했다. 디지털 PDF를 현재 코드로 추출한 결과가 과거 전체 추출 기록과 같았고 표 9셀·저장 B→A 순서·수동 두 열·검색용 합쳐진 줄을 대조했다. PDF/PNG/정답/라이선스는 기준 Git Blob 및 PDF SHA256과 일치했다. 저장 미리보기 3개와 현재 mixed PDF를 새로 렌더링한 2쪽을 화면으로 확인했다. PDF를 재생성/수정하지 않았다.

정규화 10개 Locator의 현재 원본 연결, BM25→문맥→물리 1쪽 bbox 일치와 ‘영수증’/‘영수증을’의 단순 어절 차이, 삭제 후 이전 검색 선택 거부를 확인했다. 권한·엄격한 상태 flag·줄/ID/버전/텍스트 위조·Parser/원본 변경·언어 미준비/인수 거부를 검사했다. 호출자 page/bbox보다 정규 추출 기록을 사용함도 확인했다. 실제 인증·자동 하이라이트·LLM injection 방어 시험은 아니다.

과거 scan/degraded/threshold175 추출의 고정 평가 영역에서 현재 OCR 지표 함수를 실행해 저장 3조건과 일치함을 확인했다. 정답은 공백 제외 40문자·공백 토큰 14개이며 깨끗한 스캔은 문자 편집 1/단어 편집 6이다. 제목 치환과 금액 누락 모두 CER 2.5%지만 금액 필드 존재는 다름을 계산했다. 좌표 예의 1785×2526픽셀→595×842point 산술도 확인했다. 필수 실습 Bash 6블록·기록 읽기 네 모드와 잘못된 인자를 실행했다.

## 환경·미실행·보존

pdfplumber 0.11.9/pypdf 6.10.0/Pillow 12.3.0/ReportLab 4.4.9와 Tesseract 5.3.4다. 보조 Pydantic 2.14.1은 고정 2.14.2와 다르다. 현재 시스템 언어는 eng/osd이며 한글 데이터가 없어 언어 미준비 거부만 확인했다. 새 자산 다운로드·한글 OCR/전처리·전체 document_tests/기존 ML Pytest·CLIP/VLM/OCR-free/Layout-aware 모델·RAG 답변·일반 문서 벤치마크·독립 채점/교육장 수업은 미실행이다. 저장 OCR 대조를 새 OCR로 표시하지 않는다.

현재 직접 검사 프로세스의 연결 시도는 없었고 OS 네트워크 격리 증거는 아니다. 원본/과거 결과·의존성·추출기/검색기·품질 게이트를 보존했으며 새 도구는 로컬 JSON 읽기만 한다. 근거와 범위는 [검증 기록](validation.json)에 남긴다.

다음은 Document AI 앞 세 단원과 L9 해당 활동이다. 원본/버전·권한 상태가 검색 근거·검토·생성 문서로 이어지는 과정을 풀어야 하므로 **추천 추론 강도는 High**다. Provider·React/Streaming·최종 평가는 후속 세 단원으로 분리한다.
