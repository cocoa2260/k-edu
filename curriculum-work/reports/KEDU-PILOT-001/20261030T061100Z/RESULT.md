# 첫 강의 분석 결과 — AI·머신러닝·딥러닝 개요

**추천: 기초 정의를 반복하는 부분은 줄이고, 데이터와 평가를 설계하는 강의로 재구성하자.**

강의 전체를 읽고 Phase1 관련 강의 3개와 비교했다. 강의 본문을 고치거나 과목을 삭제한 것은 아니며, 이번에는 한 과목의 분석·검증까지 마쳤다.

## 무엇을 줄이고 무엇을 남길까?

| 내용 | 판단 | 추천 |
|---|---|---|
| AI·ML·DL 정의와 포함 관계 | Phase1에서 이미 설명함 | 짧은 연결로 대체 |
| 사람이 규칙을 작성하는 방식과 데이터로 학습하는 방식 | 예시 소재는 달라도 설명 구조가 반복됨 | 재설명을 줄이고 오류·평가 문제로 확장 |
| Training·Inference, Loss·Parameter·Hyperparameter | Phase1에는 실제 값을 비교하는 코드까지 있음 | 다시 정의하기보다 평가 설계와 연결 |
| Train·Validation·Test, 과적합, Data Leakage | Phase1의 예고보다 구체적인 학습 성과가 있음 | 핵심으로 보존 |
| Precision·Recall과 업무 오류의 피해 | 모델 점수와 실제 업무 목적을 연결함 | 핵심으로 보존 |
| 신경망 층·Activation, 학습 방식 구분 | 기초와 겹치는 부분도 있고 새 원리도 있음 | 새 원리는 보존하고 중복만 차별화 |
| CNN·RNN·Transformer 등의 소개 | Phase1의 다른 교시와 추가 비교가 필요함 | 아직 이동·삭제를 결정하지 않음 |

**실제로 다듬을 부분도 발견했다.**

- 앞에서는 학습 방식과 모델 구조의 분류 기준을 구별하지만, 뒤의 요약 그림에서는 같은 계층으로 묶고 있다.
- 데이터·평가의 핵심 내용이 ‘다음 강의 안내’ 뒤의 보강 학습에 놓여 있다. 본문 흐름으로 끌어오는 편이 좋다.
- 실습은 이미 존재하지만 종이·Markdown 설계 활동이다. 6행 Dataset을 쓰라는 지시에 대응하는 완성된 표와 실행 코드까지 있는 것은 아니다.

## 어떻게 바꾸면 좋을까?

이 강의는 다음 흐름을 검토할 만하다.

1. 이미 배운 용어를 짧게 확인한다.
2. 무엇을 입력하고 무엇을 맞힐지 정한다.
3. 학습·선택·최종평가 데이터를 나눈다.
4. 새 데이터의 성능과 누수 여부를 판단한다.
5. 어떤 실수가 더 위험한지 보고 평가 지표를 선택한다.
6. 전체 학습·추론 Pipeline을 한 장으로 설계한다.

Activation·표현 학습·학습 신호 구분은 별도로 보존한다. 전체 목차를 정할 때 적절한 신경망·학습 원리 단원에 연결해야 하며, 이 평가 흐름에 맞지 않는다는 이유로 빼면 안 된다. 과목명·통합 여부·최종 순서·교육시간은 아직 확정하지 않았다.

| 항목 | 결과 |

중복·교육 품질 검토는 같은 Work 세션에서 수행했다. 검사 확인용 오류는 복사본에만 넣었으며 실제 초안의 문제와 구분했다. 전체를 자동 실행하는 Runner, 단계별 추론 강도 전환, Ollama·RAG·Multi-Agent 실행은 이번에 만들거나 검증하지 않았다. Token 사용량과 시간 절감률도 측정하지 않았다.
