## 4. 관찰 해석

1. KO/EN/SHORT의 문자 수와 Token 수를 비교하고, 이를 언어 능력 평가로 사용할 수 없는 이유를 쓴다.
2. Token 표시가 어색해도 decode가 원문과 맞을 수 있는 이유를 쓴다. 실제 복원 결과도 함께 적는다.
3. 길이 8과 16에서 중요한 정보가 어떻게 달라지는지 실제 입력/결과로 설명한다.
4. Attention mask의 0인 위치가 무엇인지, 학습 정답 영역의 Loss mask와 왜 다른지 설명한다.
5. Chat Template 결과에서 역할·제어 문자열을 찾고, 이것이 생성된 답변인지 설명한다.
6. Template 뒤 특수 Token 자동 추가를 켰을 때 실제 ID가 바뀌었는지, 바뀌지 않았다면 무엇을 확인할지 쓴다.
7. 프로필을 바꿨을 때 같은 숫자 ID를 같은 뜻으로 해석해도 되는지 설명한다.
