# Dataset Card — 가상 시설 규정 응답 연습 v1

**교육용 SFT 준비 자료이며 실제 기관 규정·운영 권한·성능 보증이 아니다.** [강의](../../../../lessons/fine-tuning/lesson.md)의 U02/U03과 [실제 검토](../../../../reports/KEDU-PRODUCTION-009/REVIEW.md)에서 필요한 예를 읽는다.

## 목적·출처·사용 범위

같은 Work의 AI가 새로 작성한 한국어 가상 규정과 교사 정답 초안이다. 실제 강사·교육생의 독립 검수는 아직 없다. 기존 출장/교육비 평가 자료를 재사용한 훈련 예제가 아니다. 문서에 따라 한도·조건·예외를 답하거나, 필요한 조건을 묻거나, 근거 부족·접근 제한을 설명하는 행동을 연습한다. 출처는 그룹 Manifest에 기록했다. 외부 데이터·개인정보·유료 합성 API는 사용하지 않았다.

로컬 교육 준비와 이후 제한된 학습 실험용이다. 데이터 파일을 이용할 때 저장소의 적용 조건도 확인한다. 이 Card가 제3자 자료나 별도 Base 모델의 라이선스를 대신하지 않는다. Base 모델의 ID·Revision·적용 조건은 별도로 고정한다.

## 원문 가족별 분리

| 분리 | 원문 그룹 | 가상 한도 | 조건·예외 |
|---|---|---|---|
| Train | 연구실 회의실 | 2시간 | 사전 예약·음식 반입 금지 |
| Train | 실험 장비 대여 | 3일 | 대여 등록·재대여 금지 |
| Train | 도서관 인쇄 | 40장 | 학생증 제시·컬러 인쇄 제외 |
| Train | 현장 보관함 | 2주 | 사용 신청·공유 금지 |
| Validation | 영상 스튜디오 | 90분 | 사전 예약·야간 제외 |
| Validation | 자전거 보관소 | 2일 | 등록·배터리 충전 금지 |
| Test | 천체 관측실 | 60분 | 사전 신청·음료 반입 금지 |
| Test | 음성 녹음실 | 45분 | 예약 확인·동반 입장 금지 |

각 가족의 다섯 원본 예제와 파생 질문은 같은 Split을 유지한다. Train 원본 20개, Validation 10개, Test 10개다. Train 바꿔쓰기 8개를 더해 실제 준비 대상은 28/10/10, 총 48개다. 기각 후보 4개는 Training에 넣지 않는다.

기존 core-v1/agent-v1 18개는 별도 회귀 집합이다. 반복해서 검토한 공개 자료이므로 블라인드 평가가 아니다. 이 새 Test도 공개된 교사 예제이며 독립 작성·봉인된 평가가 아니다. 표면 문장 틀은 여러 그룹에서 공유한다. 소규모 동작 검증을 넘어 일반화 성능을 주장할 자료가 아니다.

## 라벨 지침

| 상황 | 목표 행동 | 좋은 예 | 나쁜 예 |
|---|---|---|---|
| 원문에 답이 있음 | answer·주장과 원문 인용 | 2시간·예약·음식 금지를 함께 답함 | 근거가 있는데 무조건 자료 부족 |
| 사용자의 전제가 틀림 | answer·잘못된 전제 교정 | 무제한이 아니라 2시간임을 설명 | 사용자의 숫자를 사실로 복사 |
| 사용자 조건이 불명확 | clarify·필요한 조건 질문 | 필요한 예약/신청 완료 여부 질문 | 질문을 그대로 되풀이 |
| 원문에 기준 없음 | abstain·없는 기준 설명 | 분실 보상금 규정이 없다고 설명 | 임의 금액 생성 |
| 신뢰 측 권한 없음 | deny·접근 제한 설명 | 원문 없이 권한 제한을 설명 | 제한 원문을 Context에 넣고 답만 숨김 |

권한 값은 학습용 신뢰 측 입력이다. 실제 사용자 인증은 아니다. deny 예제에는 제한 원문을 넣지 않는다. 문서와 질문은 user 데이터, 교사 응답은 assistant target으로 구분한다. 그룹·Split·라벨 종류·검수 메타데이터는 모델 Prompt에서 제외한다.

## 검수·증강·파일

작성자가 원문·질문·정답의 숫자·조건·예외·인용을 대조했다. 같은 Work 검토이며 독립 평가자가 아니다. 검수의 내용 해시는 검수한 내용이 바뀌지 않았는지 확인한다. 의미를 자동 판정하지 않는다.

| 파일 | 역할 |
|---|---|
| seeds.json | 원본 40개·원문·교사 응답 |
| split-manifest.json | 증강 전에 고정한 원문 가족·버전·Split |
| augmentation-candidates.json | Train 바꿔쓰기와 의도적으로 나쁜 후보, 총 12개 |
| review-manifest.json | 각 내용에 연결한 채택/기각·이유·작성자 검토 |

숫자를 20시간으로 바꾼 답변, Validation 부모 증강, 원본과 같은 중복, 원문에 없는 인용을 기각했다. 질문을 바꾸는 방법만 구현했으며 새 조건/정답을 만드는 변형은 재라벨링·새 검수를 거쳐야 한다. manual_paraphrase는 고정 작성 변형을 뜻하는 코드 이름이며 사람의 검수 증거가 아니다. 별도 로컬 모델·외부 API의 합성 파이프라인은 실행하지 않았다.

## 제한·변경 원칙

답변과 교정이 각각 8개, 나머지 세 행동이 각각 8개인 원본이다. Train 증강 뒤에는 답변 계열 12개·clarify 4개·abstain 8개·deny 4개다. 보류 행동 비중과 과도한 거부를 이후 평가에서 확인한다. 이 수량만으로 학습 데이터가 충분하다고 판단하지 않는다.

그룹 분리·정확한 중복·기존 회귀 문항 제외 검사는 의미적 유사성·오염의 완전한 부재를 보장하지 않는다. 내용·라벨·Split을 바꾸면 검수 해시와 Dataset 버전을 새로 만들고, Test를 본 뒤 설정을 골랐다면 해당 Test의 사용 이력도 밝힌다. 원문을 고치고 이전 검수 해시만 재사용하지 않는다.
