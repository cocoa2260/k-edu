# L7 실습 — Dataset과 학습 입력 준비

**L7 데이터 준비·전체 Train 포함 학습·회귀 안내다. 품질 채택·QLoRA·독립 수업 검증은 미완료다.** [강의](../../lessons/fine-tuning/lesson.md) → [데이터·입력 검토](../../reports/KEDU-PRODUCTION-009/REVIEW.md) 순서로 본다. 아래 데이터 준비 명령은 모델 가중치나 답변 생성을 호출하지 않는다. 실제 훈련 명령은 문서 마지막에 있다.

## 환경과 실행

검증 환경은 Linux x86_64·Python 3.12 CPU다. L5의 고정 패키지를 유지하고 Datasets 4.4.1을 별도 환경에 추가했다. 이번 제작 환경에서는 큰 패키지를 다시 설치하지 않도록 L5 패키지를 읽기 전용으로 참조하는 별도 설치 계층을 사용했다. 아래 학생용 새 환경 설치 순서는 표준 pip 방식이다. 다른 OS·교육장 PC의 동시 실행은 별도 검증 대상이다.

backend 폴더에서 새 가상환경을 활성화한 뒤 실행한다. 표는 **입력할 명령**이며 관찰 결과 예시가 아니다.

| 목적 | 입력할 명령 |
|---|---|
| Linux CPU Torch 준비 | `python -m pip install torch==2.15.0+cpu --index-url https://download.pytorch.org/whl/cpu` |
| 고정 준비 의존성 설치 | `python -m pip install -r requirements-training-data.txt` |
| 최초 Tokenizer 준비와 Dataset 처리 | `python -m tools.training_data_lab --download --output l7-data-01` |
| 캐시만 사용하는 재실행 | `HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 HF_HUB_DISABLE_TELEMETRY=1 python -m tools.training_data_lab --output l7-data-02` |
| 기존 회귀·데이터/Mask 경계 검사 | `python -m pytest -q` |

처음에는 같은 Qwen3-0.6B 리비전의 Tokenizer 파일을 받는다. Qwen 가중치는 필요하지 않다. 기존 L4/L5 모델 캐시와 HF_HOME을 따로 정했다면 같은 값을 유지한다. 원격 문서의 최신 API와 이 고정 실행 버전을 혼용하지 않는다.

출력 폴더가 있으면 덮어쓰지 않는다. 원본/검수/코드/Tokenizer 변경 후에는 새 폴더에 실행한다. 로컬 JSON을 읽어도 Datasets Library가 사용 횟수 통계용 HEAD 요청을 시도할 수 있어, 엄격한 캐시 재실행에서는 위 세 환경 값을 프로세스 시작 전에 지정했다. 실제 요청 가드 확인 범위는 결과 보고서에 있다.

## 실제 처리 순서

1. 원본 예제 Schema·원문 버전·라벨·검수 해시·가족 Split을 확인한다.
2. Train 부모의 바꿔쓰기만 검사하고 채택/기각 이유를 남긴다.
3. 로컬 JSONL을 Datasets로 읽어 Features·Split·샘플을 확인한다.
4. 공백 filter 후 map으로 실제 Template·Token·label을 만든다. 이번 공백 제거 수는 0이며 의미 검사를 대신하지 않는다.
5. Arrow로 저장하고 다시 읽어 모든 행·Token·label의 동일성을 확인한다.
6. 길이가 다른 두 예제를 Padding해 EOS/Pad 구분과 가짜 Logit의 무시 위치를 검사한다.

원본 Train 20개와 증강 Train 28개를 구분한다. 실제 비교 학습에서는 부모 ID가 없는 Train만 고르면 원본 조건이다. Validation/Test는 설정 선택·최종 확인 용도로 분리하고 Optimizer 입력에서 제외해야 한다. 이번에 학습기를 구현한 것은 아니다.

## 결과에서 확인할 것

| 출력 | 확인할 내용 |
|---|---|
| observed.json | 실제 수량·Features·후보 결정·길이·저장/재로드·환경/코드 해시 |
| train/validation/test.jsonl | 검수 후 내보낸 로컬 데이터; question·sources·target의 역할 |
| token-example.json | 한 예제의 messages·렌더링·input_ids·labels·정답 복원 |
| batch-example.json | 실제 길이가 다른 두 행과 EOS ID를 공유하는 Padding의 label |
| arrow 폴더 | 실제 Datasets 저장·재로드 대상; Git에 넣지 않음 |

Tokenizer cache가 없으면 실제 Tokenizer 테스트는 skip 이유를 표시한다. 이번 제작 검증에서는 캐시를 준비해 skip 없이 실행했다. 단위 테스트의 고정 경계와 실제 전체 Dataset 변환은 별도 증거다.

## 제출·완료 범위

목표×전략 표, Dataset Card와 라벨 지침, 원문 가족 분리표, 부모-파생 계보·채택/기각 이유, 실제 Token/label 범위표, 저장/재로드 기록을 제출한다. 자료 전체나 JSON을 사람이 하나씩 읽는 대신 검토표에서 원문·질문·정답·Mask를 함께 확인한다.

가짜 17분류 Logit 검사는 Loss mask를 확인하는 작은 수치 검사다. Qwen의 학습/검증 Loss가 아니며 모델 학습·성능 개선을 뜻하지 않는다. 실제 LoRA Parameter·Optimizer Step·메모리/시간·Validation·Base/Tuned 비교·Adapter 저장/새 프로세스 Reload와 QLoRA 실행 가능성은 남아 있다.

## 실제 LoRA 소규모 실행

[훈련 강의](../../lessons/fine-tuning/training.md)와 [실제 결과](../../reports/KEDU-PRODUCTION-010/RESULT.md)를 본다. CPU 환경에 requirements-lora.txt를 설치한다. 훈련은 모델 가중치를 내려받으며 준비 단계보다 메모리·시간이 더 필요하다.

| 목적 | backend에서 입력할 명령 |
|---|---|
| 실제 실험 | `python -m tools.lora_lab --download --output l7-train` |
| 새 프로세스 재로드 | `python -m tools.lora_lab --reload l7-train/seed-adapter --output l7-reload` |

현재 명령은 조건별 4개·4 Step의 고정 소규모 실험이다. 전체 20/28개 학습 명령으로 오해하지 않는다. 같은 HF_HOME 캐시와 Base Revision을 유지한다. 출력 폴더는 덮어쓰지 않는다. 모델 생성·Loss·Gradient·Weight 변화·파일 해시는 observed.json에 있다. 전체 18개 회귀·QLoRA·독립 품질 검증은 별도다.

## 전체 Train 포함 학습·18개 회귀

[최신 결과](../../reports/KEDU-PRODUCTION-011/RESULT.md)와 [실제 답변](../../reports/KEDU-PRODUCTION-011/REVIEW.md)을 본다. 원본 20개와 증강 28개를 각각 포함한 28 Step·한 Seed 비교다. 수렴·운영 품질 승인은 아니다.

| 목적 | backend에서 입력할 명령 |
|---|---|
| 새 실험 | `python -m tools.lora_full_lab --download --output l7-full-new` |
| 같은 코드·자료로 재개 | `python -m tools.lora_full_lab --resume --output l7-full-new` |
| 별도 프로세스 재로드 | `HF_HUB_OFFLINE=1 python -m tools.lora_full_reload --run l7-full-new --variant seed` |

원본과 증강은 같은 초기 Adapter·28 Step이지만 Token 노출량은 다르다. Validation으로 후보를 고정한 뒤 Test를 실행한다. Agent 회귀는 기존 18개와 Registry·정책·상한을 유지한다. KV cache는 훈련에서는 끄고 추론에서는 켠다. 예전 소규모 실험과 시간 비교를 하지 않는다. Step별 저장이 완성된 후 완료 포인터를 바꾸며, 코드/자료/환경이 바뀌면 재개를 거부한다. 원본 관측 폴더는 이전 체크포인트 소스로 실행됐으므로 현재 명령은 새 폴더에 사용한다.
