# Provider와 전송 상태 및 최종 평가 해설

[Provider](provider.md), [Streaming](streaming.md), [최종 평가](evaluation.md)와 [연결 실습](../../practice/document-assistant/L9.md)의 판단 근거다. 앞 세 단원의 [해설](teacher-guide.md)은 그대로 사용한다. 같은 작성자의 설명 검수이며 독립 수업/업무 승인과 구분한다.

## Provider 기능과 예산

1. **text 준비 완료는 Vision 지원이 아니다.** 필요한 기능·전송 범위가 맞아야 하며 원문 접근 허용과 외부 전송 허용도 다르다. scope 거부는 readiness 호출보다 먼저 일어난다. readiness는 시각/유효 기간을 가진 어댑터의 관찰이지 모든 후속 생성의 성공 보장이 아니다. 가짜 Tokenizer/프로필 검사를 실제 Qwen 실행으로 설명하지 않는다.
2. **한 시도는 5+16=21, 두 시도는 42 예약이다.** Context 20은 첫 입력/출력 여유부터 초과한다. Context가 충분해도 공유 예약 41이면 첫 실패의 21을 유지한 채 다음 21을 예약할 수 없어 backup 호출을 막는다. 공유 호출 한도 1도 첫 시도 뒤 차단한다. 문자 수 Fixture와 모델 Token/실제 청구액을 구분한다. 성공의 보고 사용량 5/5를 근거로 실패 예약을 지우지 않는다.
3. **늦은 응답을 사용자에게 쓰지 않는 것과 계산을 즉시 끝내는 것은 다르다.** 현재 동기 Router는 생성 전후 시간/취소를 확인한다. 어댑터가 TemporaryFailure로 정규화한 일시 오류만 남은 같은 예산에서 다른 후보로 보낸다. 인증/정책/알 수 없는 오류·비어 있거나 모순인 출력·출력 길이 상한을 모두 재시도 사유로 삼지 않는다.

실습의 실제 loopback HTTP는 정상 대체 2회, 기능 거부 0회, 호출 제한 1회, 예약 제한 1회로 총 4요청이다. 이는 모델 호출 4회나 원가 실험이 아니다. Trace의 결정 순서와 최종 answer 존재 여부를 함께 설명하는지 본다.

## 바이트·이벤트·화면

1. **한글 글자의 UTF-8 바이트도 조각 사이에서 나뉜다.** ‘한’의 ED 95 9C가 ED 95와 9C로 오면 TextDecoder가 미완성을 보존해야 한다. 그 뒤 SSE 줄/빈 줄을 모으고 data JSON을 해석한다. 네트워크 조각 수·SSE 이벤트 수·모델 Token 수를 같다고 가정하지 않는다. 한 번에 여러 이벤트도 올 수 있다.
2. **delta는 draft만 바꾸고 final completed에서 일치한 answer만 확정한다.** 정상 프레임 두 개가 왔어도 final 없이 EOF면 앱의 missing_final이다. final answer가 draft와 다르면 거부한다. 전송 완료여도 사실/근거·업무 승인까지 확인한 것은 아니다. 일반 SSE EOF 처리와 이 앱의 더 엄격한 완료 규칙을 구분한다.
3. **A의 취소 확인은 A에만 속한다.** B 실행을 시작하면 새 ID/세대를 쓰고 늦은 A 콜백은 B 화면을 바꾸지 않는다. 취소 접수 ack는 서버의 고정 전송 루프에 요청이 전달됐다는 뜻이며 GPU 모델 강제 중단이 아니다. 확정 answer를 비우고 부분 문장을 구분해 남긴다.

실습의 메모리 Response/한 바이트 조각 코드는 프로토콜 검사이며 실제 TCP나 모델 생성 시험이 아니다. 실제 브라우저의 모든 TCP 분할을 관찰했다고 확대하지 않는다. React는 Parser 상태를 그리는 층이고 명령 실행 시 자동 재호출/재연결을 하지 않는다. 취소 세대 가드가 어째서 필요한지 기존 코드의 콜백과 연결한다.

DOM에 한글이 있어도 글꼴이 없으면 네모로 보인다. 자동 상태 검사가 통과한 뒤 화면에서도 글꼴·상태/오류·부분 답변 설명·가로 넘침을 확인한다. 모바일 크기는 실제 휴대전화/다른 브라우저 검증과 구분한다.

## 최종 채택 판단

1. **세 고정 예제의 추출/표/위치 일치만 확인했다.** 문서 구성과 레이아웃이 다른 일반 자료·복잡한 표·OCR·실제 모델/Agent·인증·독립 수업은 별도 게이트다. DOCX에서 15000원 셀과 위치가 있어도 사용 이력/부담금 관계를 직접 대조해야 한다. 초안 70개 파일 작성과 설명 정비·수업 가능성도 다른 수치다.
2. **빈 Token/청구액은 미측정이다.** 모델을 호출하지 않았다는 사실을 무료 운영 보장으로 바꾸지 않는다. 세 파일은 길이·압축/스타일·구성·캐시가 달라 한 번의 시간/바이트 수로 형식의 우열을 말하지 않는다. 정답 보존·실패율·대표 문서와 반복 분포를 함께 평가한다.
3. **재출력 차단은 앞으로 같은 명세로 새 파일을 만들지 못하게 한다.** 이미 저장/복사한 파일을 회수하는 기능이 아니다. 현재 원문·내용 해시·검토 결정을 다시 확인해야 하며 배포 후 회수/보관 정책은 별도로 설계·검증해야 한다.

고정 검토자가 approve를 선택하는 실습은 독립 의미 채점이나 실제 사용자 승인이 아니다. 학생이 ‘예제 소프트웨어 계약 통과, 사용 채택 보류’처럼 근거 수준을 나눠 말하는지 확인한다. 검증하지 않은 항목은 모르겠음/미실행/미측정으로 남기게 한다.
