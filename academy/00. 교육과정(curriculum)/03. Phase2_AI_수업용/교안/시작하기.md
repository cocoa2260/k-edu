# 시작하기 — AI 문서 도우미 첫 실행

우리는 React와 FastAPI를 연결한 **하나의 문서 도우미 프로그램**을 끝까지 발전시킵니다. 오늘은 일반 Chat이 응답하도록 하는 것이 목표입니다. 문서 검색이나 RAG는 아직 구현하지 않았습니다.

## 오늘 순서

1. [부록: Python 가상환경 만들기](<부록. Python 가상환경 만들기.md>)를 처음부터 따라 **Ollama Qwen3 모델 준비**와 **Python 가상환경 생성**을 합니다.
2. VS Code에서 `실습앱/` 폴더를 열고 [`실습앱 README`](<../실습앱/README.md>)를 따라 FastAPI와 React를 각각 실행합니다.
3. 브라우저 `http://127.0.0.1:5173`에서 한국어 질문을 보내고 응답 또는 오류를 확인합니다.
4. `http://127.0.0.1:8000/health`는 설정 확인만 하고, 실제 모델 생성 여부는 **브라우저에서 질문을 보낸 결과**로 따로 판정합니다.
5. `backend/data/fixtures/`에는 앞으로 사용할 가상 규정 6개와 테스트용 질문 12개가 있지만, 현재 일반 Chat은 이 자료를 **검색하거나 근거로 사용하지 않습니다**.

## 수업에서 계속 유지할 것

- `backend/`와 `frontend/`는 삭제하지 않습니다. 다른 단원에서도 **같은 앱**을 수정합니다.
- `.env`·`.venv`·`node_modules`는 학생 컴퓨터에서 생성하며 Git이나 공유 ZIP에 올리지 않습니다.
- 다음 수업에서는 입력을 구성하는 `prompting.py` 등을 학생이 직접 추가합니다. 이미 완성된 Agent/RAG 코드는 시작본에 없습니다.

**실행 결과 기록:** 모델 이름, 실제 답변 수신 여부, 연결 오류 여부를 구분해서 기록합니다. 답변이 자연스러워도 가상 규정의 정확한 수치와 일치한다는 뜻은 아닙니다.
