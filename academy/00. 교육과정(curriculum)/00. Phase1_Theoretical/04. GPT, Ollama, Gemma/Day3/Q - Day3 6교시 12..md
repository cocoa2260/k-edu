여기서 말하는 핵심은 **“LangChain을 사용한다고 해서 반드시 Agent를 만들어야 하는 것은 아니다”**입니다.

앞에서 본 Standard Model Interface와 바로 연결되는 내용입니다.

### 1. LangChain으로 가장 단순하게 Model만 호출할 수 있습니다

예를 들어 Ollama의 Qwen을 LangChain을 통해 호출한다고 해보겠습니다.

```python
from langchain_ollama import ChatOllama

model = ChatOllama(
    model="qwen3:1.7b"
)

response = model.invoke(
    "RAG를 한 문장으로 설명해줘."
)

print(response.content)
```

이 코드에는 **Agent도 없고 Tool도 없고 RAG도 없습니다.**

구조는 정말 이것뿐입니다.

```text
Python Application
↓
LangChain Model Interface
↓
Ollama Integration
↓
Ollama
↓
qwen3:1.7b
```

즉 강의안에서 말하는 다음 구조가 이것입니다.

```text
Application
↓
LangChain Model Interface
↓
Model
```

### 2. 그러면 LangChain을 왜 사용하는가?

“Model 하나 호출할 거면 그냥 Ollama API를 직접 호출하면 되는 거 아닌가?”

**맞습니다.**

예를 들어 우리가 이전에 배운 방식으로:

```python
import httpx

response = httpx.post(
    "http://localhost:11434/api/chat",
    json={
        "model": "qwen3:1.7b",
        "messages": [
            {
                "role": "user",
                "content": "RAG를 설명해줘."
            }
        ]
    }
)
```

처럼 직접 호출할 수도 있습니다.

LangChain을 사용하면:

```python
model = ChatOllama(model="qwen3:1.7b")

response = model.invoke("RAG를 설명해줘.")
```

처럼 LangChain의 Model Interface를 통해 호출할 수 있는 겁니다.

따라서 차이를 단순화하면:

```text
직접 호출

Application
↓
httpx
↓
Ollama API
↓
Model
```

```text
LangChain 사용

Application
↓
LangChain Model Interface
↓
Ollama Integration
↓
Ollama
↓
Model
```

LangChain을 사용했다고 해서 자동으로 Agent가 생긴 게 아닙니다.

### 3. Agent는 그 위에 추가할 수 있는 기능입니다

Model 단독 호출보다 더 복잡한 요구사항이 생겼다고 생각해보죠.

사용자가 이렇게 질문합니다.

```text
"우리 회사 문서에서 홍길동의 담당 프로젝트를 찾아줘."
```

Model 자체는 회사 문서에 접근할 수 없습니다.

그래서 Tool을 연결하고 Agent를 구성할 수 있습니다.

```text
User
↓
Agent
↓
Model
↓
"문서 검색이 필요하겠다"
↓
search_document Tool
↓
검색 결과
↓
Model
↓
최종 답변
```

이게 강의안 뒤쪽에서 설명하는 Agent 영역입니다. 강의안 역시 Agent를 Language Model과 Tool을 결합하여 Task를 해결하는 System으로 설명하고 있습니다.

따라서 관계를 이렇게 이해하면 가장 쉽습니다.

```text
LangChain
│
├── Model만 사용
│   └── model.invoke(...)
│
├── Model + Tool
│
├── Model + Retrieval
│
└── Model + Tool + Agent
```

**LangChain = Agent**가 아니라,

**LangChain이 제공하는 여러 기능 중 하나가 Agent**인 것입니다.

수업에서는 이렇게 한마디로 정리하면 좋습니다.

> **LangChain은 Agent 전용 Library가 아닙니다. Model 하나만 LangChain의 공통 Interface로 호출할 수도 있고, 필요해지면 그 위에 Tool, Retrieval, Agent 같은 기능을 추가할 수 있습니다.**

그리고 지금 `#12`가 `#10 Standard Interface` 바로 다음에 나오는 이유도 여기에 있습니다. **앞에서 배운 `model.invoke()` 자체가 이미 LangChain을 사용하는 하나의 완전한 형태**라고 연결해서 설명하면 됩니다.
