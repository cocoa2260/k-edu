쉽게 말하면 **Model Capability는 "이 모델이 어떤 일을 할 수 있는가?"**입니다. 강의안에서 말하는 항목들은 모델의 주요 능력을 구분해서 보는 기준입니다.

```text
Text Generation
→ 글을 생성할 수 있는가?

Instruction Following
→ "요약해줘", "번역해줘" 같은 지시를 잘 따르는가?

Multilingual
→ 한국어, 영어 등 여러 언어를 처리할 수 있는가?

Code
→ Python, JavaScript 같은 코드를 이해하고 생성할 수 있는가?

Reasoning
→ 여러 정보를 바탕으로 문제를 분석하고 추론할 수 있는가?

Multimodal
→ Text뿐 아니라 Image 등의 다른 형태의 입력도 처리할 수 있는가?

Function / Tool 관련 지원
→ 외부 함수나 도구를 호출하는 방식으로 사용할 수 있는가?
```

예를 들어 우리가 **한국어 PDF 요약 AI**를 만든다고 하면,

```text
필요한 Capability

한국어 처리        → Multilingual
문서 내용 이해     → Text 처리
내용 요약          → Text Generation / Instruction Following
복잡한 내용 분석   → Reasoning
이미지를 직접 입력 → Multimodal (필요한 경우)
```

처럼 프로젝트에 필요한 능력을 먼저 생각할 수 있습니다.

다만 **Model Card에 "Reasoning", "Multilingual"이라고 적혀 있다고 해서 우리 프로젝트에서도 무조건 잘한다는 뜻은 아닙니다.**

그래서 마지막 문장이 중요합니다.

> **Capability는 "이 모델이 무엇을 할 수 있는지"를 보여주는 정보이고, 실제로 우리 프로젝트에서 얼마나 잘하는지는 직접 Evaluation해야 합니다.**
