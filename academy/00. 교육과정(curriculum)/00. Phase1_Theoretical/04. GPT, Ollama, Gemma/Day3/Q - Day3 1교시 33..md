이 순서는 **"유명한 모델부터 고르는 게 아니라, 프로젝트 요구사항에서 출발해서 최종 모델을 결정하는 과정"**입니다. 강의안의 앞부분에서 배운 Model Family, Variant, Model Card, Runtime 등을 실제 선택 과정으로 연결한 것입니다.

예를 들어 **"로컬에서 한국어 문서를 요약하는 AI"**를 만든다고 해보겠습니다.

```text
1. Requirement
   ↓
우리가 무엇을 만들어야 하는가?

예)
- 한국어 문서 요약
- 외부 API 사용 불가
- 16GB RAM 노트북
- Ollama로 실행
```

먼저 모델이 아니라 **프로젝트가 무엇을 요구하는지** 정합니다.

```text
2. Candidate Family
   ↓
어떤 Model Family가 적합할까?

예)
Gemma?
Qwen?
Llama?
```

요구사항을 만족할 가능성이 있는 **Model Family 후보**를 찾습니다.

```text
3. Candidate Variant
   ↓
그 Family에서 어떤 Variant를 사용할까?

예)
Gemma 계열
├─ 작은 Size
├─ 큰 Size
├─ Pre-trained
└─ Instruction-tuned
```

같은 Family에도 여러 모델이 있기 때문에 **정확한 Variant 후보**까지 좁힙니다.

```text
4. Model Card
   ↓
이 모델이 정확히 어떤 모델인가?

- Parameter Size
- Input / Output
- Context
- Language
- Capability
- Limitations
...
```

여기서 이름만 보고 추측하지 않고 **공식적인 모델 정보를 확인**합니다.

```text
5. License / Terms
   ↓
우리 프로젝트에서 사용해도 되는가?

- 사용 조건
- 배포 조건
- 상업적 이용 관련 조건
...
```

기술적으로 사용할 수 있는 것과 **법적·정책적으로 사용할 수 있는 것**은 별개이므로 확인합니다.

```text
6. Hardware
   ↓
우리 컴퓨터에서 돌릴 수 있는가?

- RAM
- VRAM
- GPU
- Storage
...
```

아무리 좋은 모델이어도 현재 장비에서 실행할 수 없다면 적절한 후보가 아닐 수 있습니다.

```text
7. Runtime Compatibility
   ↓
우리가 사용할 실행 환경에서 지원하는가?

예)
Ollama에서 실행 가능한가?
Transformers에서 사용할 수 있는가?
필요한 Model Format은 무엇인가?
```

**Model과 Runtime은 별개**이기 때문에 호환성을 확인합니다.

여기까지가 일종의 **서류 심사**라고 생각하면 쉽습니다.

그다음부터 실제로 돌려봅니다.

```text
8. Small Test
   ↓
일단 작은 규모로 실행해본다.

예)
한국어 문서 5개를 넣어서
요약 결과를 확인
```

바로 전체 시스템에 적용하지 않고 먼저 **작게 테스트**합니다.

```text
9. Evaluation
   ↓
정말 우리 프로젝트에서 잘하는가?

- 요약이 정확한가?
- 중요한 내용을 빠뜨리지 않는가?
- 한국어가 자연스러운가?
- 응답 속도는 괜찮은가?
- Memory 사용량은 괜찮은가?
```

Model Card에 성능이 좋다고 적혀 있는 것과 **우리 Task를 잘 수행하는 것은 다른 문제**이므로 실제 데이터를 가지고 평가합니다.

마지막으로:

```text
10. Selection
    ↓
최종 Model 결정
```

평가 결과를 바탕으로 최종 모델을 선택합니다.

전체를 한 문장으로 줄이면:

> **무엇이 필요한지 정하고(Requirement) → 가능한 모델 후보를 찾고(Candidate) → 사용할 수 있는 모델인지 확인하고(Model Card, License, Hardware, Runtime) → 직접 시험하고(Test, Evaluation) → 최종 모델을 선택(Selection)하는 과정입니다.**

그래서 이 순서에서 학생들에게 가장 강조할 부분은 **`Selection`이 생각보다 맨 뒤에 있다는 것**입니다.

```text
❌ "Gemma가 유명하네? → Gemma 쓰자."

⭕ "우리 프로젝트 요구사항이 이렇다.
   → 어떤 모델들이 후보가 될까?
   → 실제 환경에서 사용할 수 있을까?
   → 직접 평가해보니 어떤 모델이 가장 적합하지?
   → 이 모델을 쓰자."
```

이게 바로 앞에서 계속 이야기한 **"좋은 모델을 찾는 것"이 아니라 "우리 프로젝트에 적합한 모델을 찾는 것"**이라는 Model Selection의 핵심입니다.
