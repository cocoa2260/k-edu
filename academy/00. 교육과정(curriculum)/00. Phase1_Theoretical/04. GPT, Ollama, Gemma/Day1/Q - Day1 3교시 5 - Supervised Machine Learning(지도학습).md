**Supervised Machine Learning(지도학습)**은 **입력 데이터와 정답(Label)을 함께 주고, 입력에서 정답을 예측하는 규칙을 학습시키는 Machine Learning 방식**입니다.

예를 들어 고객 이탈 예측이라면:

```text
고객 데이터(Input)
+
실제 이탈 여부(Label)
        ↓
Training
        ↓
Model
```

학습 데이터가 다음과 같이 있다고 생각하면 됩니다.

```text
고객 A의 정보 → 이탈함
고객 B의 정보 → 이탈하지 않음
고객 C의 정보 → 이탈함
```

Model은 이런 데이터를 반복해서 학습하면서 **고객 정보와 이탈 여부 사이의 패턴**을 찾습니다.

학습이 끝나면 새로운 고객에 대해:

```text
새로운 고객 정보
        ↓
학습된 Model
        ↓
이탈 가능성 예측
```

처럼 사용할 수 있습니다.

대표적인 지도학습 문제는 **분류(Classification)**와 **회귀(Regression)**입니다.

- Classification: 스팸/정상, 이탈/유지처럼 **범주를 예측**
    
- Regression: 집값, 매출처럼 **연속적인 숫자 값을 예측**
    

강의에서는 **“문제와 정답을 같이 보여주면서 공부시키는 방식”**이라고 먼저 설명하면 이해하기 쉽습니다.
