쉽게 말하면 **Machine Learning은 사람이 판단 규칙을 직접 작성하는 대신, 데이터에서 그 규칙을 학습하게 하는 방식**입니다.

```text
Data
+
Expected Result 또는 학습 신호
        ↓
Learning Algorithm
        ↓
Model
```

각각을 풀어보면:

- **Data**: 모델이 학습할 재료입니다. 예: 과거 고객의 이용 기간, 결제 금액, 접속 횟수 등
    
- **Expected Result 또는 학습 신호**: 무엇을 잘하도록 학습해야 하는지 알려주는 정보입니다. 지도학습이라면 `"이 고객은 이탈했다"` 같은 정답(Label)이 될 수 있습니다. 학습 방식에 따라 명시적인 정답이 없을 수도 있습니다.
    
- **Learning Algorithm**: 데이터를 이용하여 오류를 줄이도록 Parameter를 조정하는 학습 방법입니다.
    
- **Model**: 학습 결과 만들어진 것으로, 새로운 데이터를 입력받아 예측이나 분류 등에 사용합니다.
    

예를 들어 고객 이탈 예측이라면:

```text
과거 고객 데이터
+
실제 이탈 여부
        ↓
학습
        ↓
고객 이탈 예측 Model
        ↓
새로운 고객 데이터
        ↓
이탈 가능성 예측
```

강의에서는 **“Data와 학습 신호를 이용해서 Model을 만드는 과정이 Training이고, 그렇게 만들어진 Model을 새로운 데이터에 사용하는 것이 Inference다.”**라고 연결하면 좋습니다.
