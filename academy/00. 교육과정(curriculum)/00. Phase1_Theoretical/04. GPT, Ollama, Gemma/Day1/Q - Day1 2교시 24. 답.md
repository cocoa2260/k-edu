### 사례 A

- **AI인가?** → 아니요. 일반적인 규칙 기반 프로그램입니다.
- **누가 판단 규칙을 만들었는가?** → 개발자가 직접 `age >= 19`라는 규칙을 작성했습니다.

### 사례 B

- **어떤 종류의 AI 문제인가?** → 고객이 이탈할지 예측하는 **분류(Classification)** 문제입니다.
- **Machine Learning과 관련이 있는가?** → 예. 과거 고객 데이터에서 패턴을 학습해 신규 고객의 이탈 가능성을 예측하는 **Machine Learning** 문제입니다.

### 사례 C

- **어떤 종류의 AI인가?** → 입력된 문장을 바탕으로 새로운 이미지를 만드는 **생성형 AI(Generative AI)** 입니다.

### 사례 D

- **하나의 AI 기술만 필요할까?** → 아니요. 실제 서비스에서는 여러 기술과 애플리케이션 구성 요소가 함께 필요합니다.
- **어떤 구성 요소가 필요한가?** → 예를 들어 **파일 업로드 → PDF Parsing/OCR → 텍스트 처리 → LLM을 이용한 요약 → 결과 검증 → 사용자에게 응답**하는 구조가 필요합니다. 이후 요구사항에 따라 RAG 같은 기술도 추가할 수 있습니다.
