쉽게 말하면 **Limitation은 “이 모델을 어디까지 믿고 사용할 수 있는가?”를 확인하는 항목**입니다.

모델은 모든 상황에서 완벽하게 동작하지 않습니다. 그래서 Model Card에서 다음과 같은 한계를 확인합니다.

```text
Known Limitations
→ 제작자가 이미 알고 있는 모델의 한계

Bias
→ 특정 데이터나 집단에 편향된 결과가 나올 가능성

Unsupported Use
→ 사용을 권장하지 않거나 지원하지 않는 용도

Safety Considerations
→ 위험하거나 부적절한 결과가 발생할 가능성

Accuracy Limitation
→ 항상 정확한 결과를 보장하지 않음

Language Limitation
→ 특정 언어에서는 성능이 떨어질 수 있음

Domain Limitation
→ 의료, 법률 등 특정 전문 분야에서 성능이 부족할 수 있음
```

학생들에게는 이렇게 설명하면 충분합니다.

> **“모델이 무엇을 잘하는지만 보지 말고, 무엇을 못하는지도 확인해야 합니다.”**

예를 들어 영어 중심으로 학습된 모델을 한국어 고객 상담 서비스에 사용하려고 한다면, 모델 자체는 좋아도 **Language Limitation 때문에 프로젝트에는 적합하지 않을 수 있습니다.**

즉,

```text
Model 성능이 좋다
≠
내 프로젝트에 적합하다
```

라는 점을 알려주는 항목이 **Limitation**입니다.
