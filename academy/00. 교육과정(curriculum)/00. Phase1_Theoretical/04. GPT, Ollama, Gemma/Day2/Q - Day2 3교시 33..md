이 예제는 현재 강의안의 핵심인 **"Training을 하면 Source Code가 바뀌는 것이 아니라 Model의 Parameter가 바뀐다"**를 실제로 확인하기 위한 코드입니다.

전체 구조부터 보면 어렵지 않습니다.

```text
학습 데이터 준비
↓
Model 생성
↓
Loss Function 생성
↓
Optimizer 생성
↓
Training 전 Parameter 확인
↓
Training 1000회 반복
↓
Training 후 Parameter 확인
↓
최종 Loss 확인
```

## 1. `torch.manual_seed(42)`

```python
torch.manual_seed(42)
```

PyTorch의 난수 생성 결과를 재현하기 위해 Seed를 지정합니다.

뒤에서:

```python
model = nn.Linear(1, 1)
```

을 만들면 Weight와 Bias가 초기화되는데, 그 초기값에는 난수가 사용됩니다.

따라서 Seed를 고정하지 않으면 실행할 때 초기 Parameter가 달라질 수 있습니다.

```text
Seed 고정 X

실행 1 → weight = ...
실행 2 → weight = ...
```

반면 Seed를 고정하면 동일한 환경에서 예제를 반복할 때 같은 초기값을 재현하기 쉬워집니다.

`42`라는 숫자 자체에 특별한 의미가 있는 것은 아닙니다.

---

# 2. Training Data 준비

```python
x = torch.tensor(
    [[1.0], [2.0], [3.0], [4.0]]
)

y = torch.tensor(
    [[2.0], [4.0], [6.0], [8.0]]
)
```

학습 데이터입니다.

관계를 보면:

```text
x     y
-------
1  →  2
2  →  4
3  →  6
4  →  8
```

즉 Model에게 학습시키고 싶은 관계는:

```text
y = 2x
```

입니다.

`x`가 Input이고 `y`가 Target입니다.

그리고 앞에서 배운 Batch 관점에서 보면 현재는 **4개의 데이터를 하나의 Batch로 한꺼번에 넣는 아주 작은 예제**라고 볼 수 있습니다.

Shape은:

```text
x.shape → [4, 1]
y.shape → [4, 1]

4 → Sample 개수
1 → 각 Sample의 Feature 개수
```

입니다.

---

# 3. Model 생성

```python
model = nn.Linear(1, 1)
```

하나의 입력을 받아 하나의 출력을 만드는 Linear Layer입니다.

개념적으로:

```text
y = wx + b
```

입니다.

따라서 Model이 학습해야 하는 Parameter는:

```text
w → Weight
b → Bias
```

입니다.

`nn.Linear(1, 1)`의 두 숫자는:

```text
nn.Linear(
    in_features=1,
    out_features=1
)
```

이라는 뜻입니다.

현재 데이터가:

```text
[1.0]
[2.0]
[3.0]
[4.0]
```

처럼 각 Sample마다 하나의 Feature를 가지고 있으므로 `in_features=1`입니다.

출력도 하나의 값을 만들기 때문에 `out_features=1`입니다.

---

# 4. Loss Function

```python
loss_function = nn.MSELoss()
```

현재 Model의 Prediction이 Target과 얼마나 차이가 있는지 계산하기 위한 함수입니다.

MSE는 **Mean Squared Error**입니다.

입문 수준에서는:

```text
Prediction
     ↓
Target과 차이 계산
     ↓
차이를 제곱
     ↓
평균
     ↓
Loss
```

정도로 이해하면 됩니다.

왜 Loss가 필요했죠?

```text
Model이 얼마나 틀렸는가?
↓
Loss

Parameter를 어떻게 조정해야 하는가?
↓
Gradient
```

로 연결됩니다.

---

# 5. Optimizer 생성

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01,
)
```

여기에는 중요한 내용이 두 개 있습니다.

### `model.parameters()`

```python
model.parameters()
```

는 Optimizer에게:

> **"이 Model의 Parameter들을 업데이트해."**

라고 알려주는 것입니다.

현재 Model에서는 주로:

```text
weight
bias
```

가 해당됩니다.

### `lr=0.01`

Learning Rate입니다.

Gradient를 이용해서 Parameter를 업데이트할 때 **얼마나 크게 조정할 것인가**에 영향을 줍니다.

```text
Gradient
+
Learning Rate
↓
Parameter Update
```

현재는 `0.01`로 설정했습니다.

---

# 6. Training 전 Parameter 확인

```python
print("[Before Training]")

for name, parameter in model.named_parameters():
    print(name, parameter.detach())
```

Model이 가지고 있는 Parameter를 출력합니다.

대략:

```text
weight tensor([[...]])
bias tensor([...])
```

같은 형태가 나옵니다.

`named_parameters()`는:

```text
Parameter 이름 + Parameter 값
```

을 함께 가져옵니다.

그래서:

```python
name
```

에는:

```text
weight
bias
```

같은 이름이 들어가고,

```python
parameter
```

에는 실제 Parameter Tensor가 들어갑니다.

여기서 `detach()`는 해당 Tensor를 현재 Autograd 계산 그래프와 분리된 형태로 보겠다는 의미입니다. 이 예제에서는 **Parameter 값을 확인하기 위한 출력 용도**로 이해하면 충분합니다.

---

# 7. 실제 Training 시작

이 부분이 가장 중요합니다.

```python
for epoch in range(1000):
```

Training을 1000번 반복합니다.

현재 예제에서는 전체 `x`, `y`를 매 반복마다 사용하므로:

```text
전체 Dataset 사용
↓
1 Epoch

전체 Dataset 사용
↓
2 Epoch

...

1000 Epoch
```

가 됩니다.

그리고 한 Epoch 안에서 네 가지 핵심 작업이 일어납니다.

---

## ① Gradient 초기화

```python
optimizer.zero_grad()
```

이전 Training Step에서 계산된 Gradient를 초기화합니다.

PyTorch에서는 Gradient가 기본적으로 누적될 수 있기 때문에 새로운 Step을 시작하기 전에 초기화하는 패턴을 사용합니다.

```text
이전 Gradient
↓
zero_grad()
↓
초기화
```

---

## ② Forward

```python
prediction = model(x)
```

Training Data `x`를 Model에 넣습니다.

Model 내부에서는 개념적으로:

```text
x
↓
x × Weight + Bias
↓
Prediction
```

이 계산됩니다.

처음에는 Weight와 Bias가 우리가 원하는 값이 아니기 때문에 Prediction 역시 정답과 차이가 있을 것입니다.

예를 들어 개념적으로:

```text
Input      Prediction       Target

1    →       0.5      ≠       2
2    →       1.1      ≠       4
3    →       1.7      ≠       6
4    →       2.3      ≠       8
```

같은 상황이 있을 수 있습니다.

---

## ③ Loss 계산

```python
loss = loss_function(
    prediction,
    y,
)
```

Prediction과 Target `y`를 비교합니다.

```text
Prediction
     +
Target
     ↓
MSELoss
     ↓
Loss
```

Loss가 크다면 현재 Model의 Prediction과 Target의 차이가 크다는 의미입니다.

---

## ④ Backward

```python
loss.backward()
```

앞에서 배운 Automatic Differentiation이 등장합니다.

Loss에서 계산을 역방향으로 추적하여:

```text
Loss
 ↓
Backward
 ↓
Weight Gradient
Bias Gradient
```

를 계산합니다.

중요한 것은:

> **`backward()`가 Parameter를 수정하는 것은 아닙니다.**

Gradient를 **계산**하는 것입니다.

---

## ⑤ Parameter Update

```python
optimizer.step()
```

여기서 실제 Parameter가 변경됩니다.

```text
Gradient 계산
     ↓
optimizer.step()
     ↓
Weight Update
Bias Update
```

즉:

```python
loss.backward()
```

와

```python
optimizer.step()
```

의 역할을 반드시 구분해야 합니다.

```text
loss.backward()
→ Gradient 계산

optimizer.step()
→ Gradient를 이용하여 Parameter Update
```

---

# 8. 이것을 1000번 반복한다

따라서 Training Loop 전체를 그림으로 보면:

```text
                 ┌─────────────────────┐
                 │                     │
                 ▼                     │
              Input x                  │
                 ↓                     │
               Model                   │
          Weight + Bias                │
                 ↓                     │
             Prediction                │
                 ↓                     │
           Target과 비교               │
                 ↓                     │
                Loss                   │
                 ↓                     │
              backward()               │
                 ↓                     │
              Gradient                 │
                 ↓                     │
          optimizer.step()             │
                 ↓                     │
      Weight / Bias Update             │
                 │                     │
                 └──── 다음 Epoch ─────┘
```

반복하면서 Parameter가 점점 데이터의 관계:

```text
y = 2x
```

를 표현하는 방향으로 조정됩니다.

따라서 이상적으로는:

```text
Weight → 2에 가까워짐
Bias   → 0에 가까워짐
Loss   → 작아짐
```

을 기대할 수 있습니다.

---

# 9. Training 후 Parameter 확인

```python
print("[After Training]")

for name, parameter in model.named_parameters():
    print(name, parameter.detach())
```

Training 전과 똑같은 코드를 이용해서 Parameter를 다시 확인합니다.

여기가 **이 실습에서 학생들이 가장 중요하게 확인해야 하는 부분**입니다.

```text
Before Training

weight → 초기값
bias   → 초기값

        ↓
     Training
        ↓

After Training

weight → 2에 가까운 값
bias   → 0에 가까운 값
```

즉 Python Source Code가 바뀐 게 아닙니다.

```python
model = nn.Linear(1, 1)
```

이 코드는 그대로입니다.

**바뀐 것은 Model 내부의 Parameter Tensor 값입니다.**

---

# 10. 마지막 `loss.item()`

```python
print("Loss:", loss.item())
```

마지막 Training Step의 Loss를 출력합니다.

여기서 `loss` 자체는 Tensor입니다.

```python
print(loss)
```

하면 Tensor 형태로 보입니다.

`item()`을 사용하면 **하나의 값을 가진 Tensor에서 Python 숫자 값을 꺼낼 수 있습니다.**

```text
loss

tensor(...)
   ↓
.item()
   ↓
Python 숫자
```

그래서 로그를 출력할 때 자주 만나게 됩니다.

## 이 예제에서 학생들이 반드시 이해해야 할 것

코드 문법을 전부 외우게 하기보다는 다음 흐름을 설명할 수 있게 하는 것이 더 중요합니다.

```text
x, y
→ Training Data

nn.Linear
→ 학습할 Model

MSELoss
→ 얼마나 틀렸는지 계산

SGD
→ Parameter를 조정할 Optimizer

────────────────────────

zero_grad()
→ 이전 Gradient 초기화

model(x)
→ Prediction

loss_function()
→ Loss 계산

loss.backward()
→ Gradient 계산

optimizer.step()
→ Parameter Update
```

결국 이 4줄이 PyTorch Training의 핵심 구조입니다.

```python
optimizer.zero_grad()

prediction = model(x)
loss = loss_function(prediction, y)

loss.backward()
optimizer.step()
```

학생들에게는 **"예측하고 → 얼마나 틀렸는지 계산하고 → 어느 방향으로 고칠지 계산하고 → 실제 Parameter를 고친다"**라고 먼저 말로 설명한 뒤 코드와 대응시키면 이해하기 훨씬 쉽습니다.

```text
예측한다
→ prediction = model(x)

얼마나 틀렸는지 본다
→ loss = loss_function(prediction, y)

어떻게 고쳐야 할지 계산한다
→ loss.backward()

실제로 Parameter를 고친다
→ optimizer.step()
```

이 예제가 현재 교시의 **Parameter → Loss → Gradient → Optimizer → Training**을 하나의 코드로 연결하는 핵심 실습이라고 보면 됩니다.
