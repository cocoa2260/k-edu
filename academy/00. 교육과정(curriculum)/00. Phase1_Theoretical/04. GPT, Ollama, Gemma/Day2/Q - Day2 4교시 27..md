쉽게 말하면 **Evaluation은 “이 모델의 성능을 어떤 방법으로 측정했는가?”를 확인하는 항목**입니다.

Model Card에는 보통 모델을 평가한 **Benchmark나 점수**가 들어갈 수 있습니다. 그런데 단순히:

```text
Model A: 85점
Model B: 90점

→ Model B가 더 좋다?
```

라고 판단하면 안 됩니다.

점수를 볼 때는 **무엇으로 어떻게 평가했는지** 같이 봐야 합니다.

```text
어떤 Dataset으로 시험했는가?
→ 영어 데이터인가? 한국어 데이터인가?

어떤 Metric으로 측정했는가?
→ 정확도인가? 다른 평가 지표인가?

어떤 조건에서 평가했는가?
→ 어떤 Prompt와 설정을 사용했는가?

어떤 Model Version인가?
→ 내가 사용하려는 모델과 같은 버전인가?

내 Task와 관련 있는가?
→ 내가 만들 서비스와 비슷한 작업을 평가한 것인가?
```

예를 들어 영어 Benchmark에서 높은 점수를 받은 모델이라고 해서 **한국어 문서 요약에서도 반드시 좋은 성능을 내는 것은 아닙니다.**

그래서 실제 프로젝트에서는 결국:

```text
공개 Benchmark
+
내 프로젝트 데이터로 직접 평가
```

가 필요할 수 있습니다.

학생들에게는 한 문장으로 이렇게 설명하면 됩니다.

> **“Evaluation 점수 자체보다, 무엇을 어떤 조건으로 평가해서 나온 점수인지 확인해야 합니다.”**
